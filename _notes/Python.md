- 许多解释器具有一种优雅的共同结构：两个相互递归的函数。第一个在环境中求值表达式；第二个将函数应用于参数。

- repeat k fn 意思是把fn函数执行k次，说明在这里函数也可以作为一个参数传入
- 鲁棒性意思是抗折腾能力，一个系统面对变化异常的时候，仍然能够正常工作，不容易崩掉的能力。代码越少依赖具体实现、越依赖抽象接口，通常越鲁棒。
- 引发异常是一种中断程序正常执行流程的技术，用于指示某种异常情况已经发生，并直接返回到程序中指定用于应对该情况的封闭部分。
- Python 解释器每次在表达式或语句中检测到错误时都会引发异常。用户也可以通过 raise 和 assert 语句引发异常。
- An exception is a object instance with a class that inherits, either directly or indirectly, from the BaseException class.一般来说，任何异常实例都可以通过 raise 语句引发。raise 最常见的用法是构造一个异常实例并引发它。>>> raise Exception('An error occurred')
- 异常可以由一个外层的 try 语句来处理。一个 try 语句由多个子句组成；第一个子句以 try 开头，其余子句以 except 开头

	- 加法和乘法接收任意数量的参数进行运算
	- 减法有两种行为，如果只传入一个参数则对这个参数取反。传入至少两个参数，则用第一个参数减去后面所有参数
	- 除法也是两种行为。一个参数就取倒数。多个参数就用第一个参数除以后面所有参数

- 装饰器就是“接收一个函数，再返回一个经过加工的新函数”。利用高阶函数，在不直接修改原函数代码的情况下，给函数增加功能。
- 词法作用域是调用定义的函数时，会新创建一个frame，它的parent是定义函数时候的frame。但是动态作用域是调用函数时创建的新的frame的parent是调用这个函数的frame。这会导致一样的变量名但是查找顺序不同导致最终函数值会不同
