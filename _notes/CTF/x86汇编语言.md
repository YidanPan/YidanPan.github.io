## 2.x86汇编语言
### 2.1**x86 汇编语言简介**：
值得一提的是，世界上有许多种不同的汇编语言；因为有很多种不同设计目标和应用场景的计算机，而“处理器（CPU）”是所有这些设备的大脑。所以，为了控制这些不同的处理器，人们发展出了好几种不同的汇编语言。手机会使用专门针对低功耗设计的处理器，比如 **ARM 处理器**；而台式机则会使用更强大、更快速、功能更多的处理器，比如英特尔（Intel）和 AMD 自家的 **x86 处理器**！ ; 这也是我们将要学习的，因为你在“真实自然环境”中要去漏洞利用（Exploit）的大多数服务，都会运行在重型 x86 计算机上——顺带提一句，正因为它的设计极其强悍，所以它要**复杂得多**，以至于在实现处理器的指令时偶尔会出现一些小故障，我们称之为**漏洞（Vulnerabilities）**，利用这些漏洞我们可以做出设计之外的事情——比如泄露数据。

_start: ; 这是一个“标签（Label）”…… 它本身并不是一条机器指令。它只是写给我们人类看的标记。我们把它放在这里是为了以后方便引用。这样一来，如果我们后面在代码里提到了 `_start`，NASM 编译器就会知道我们指的是这个标签紧跟在后面的那个元素。

cli ; 这条指令你平时在写普通程序时基本见不到…… 所以不用太担心。它的作用大概就是：就算你此时往电脑上插个 USB 闪存盘，也不会把处理器吓跑而打断我们的核心工作。

## 2.2 基础知识
- **计算机三大语言**：高级语言（java、c等）；汇编语言（mov ax，0）；机器语言（二进制）
- CPU 可以执行机器指令，进行运算
- **寄存器**：CPU 中可以存储数据的器件(可以暂且理解为变量)
- **汇编语言组成**：
    - 汇编指令：有对应的机器码，是机器码的助记符
    - 伪指令：由编译器执行，没有对应机器码
    - 其他符号（+-*/ 等）：由编译器识别，没有对应机器码
- CPU 从内存读取数据的过程：
    - CPU 通过地址线将地址信息发出
    - CPU 通过控制线发出内存读命令，告知指定存储器芯片要从中读取数据
    - 存储器将所需地址处的数据通过数据线送给 CPU
- 存储器芯片从读写上分为 随机存储器（RAM）和 只读存储器（ROM）
    - RAM 可读可写，但必须带电存储，关机后内容丢失
    - ROM 只读不写，但关机后内容不丢失
