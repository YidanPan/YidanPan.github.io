1.基础语法

字符串

  • 反斜杠可以用来转义，使用 r 可以让反斜杠不发生转义。 如 r”this is a line with \n” 则 \n 会显示，并不是换行
  • 按字面意义级联字符串，如 “this “ “is “ “string” 会被自动转换为 this is string。
  • 字符串可以用 + 运算符连接在一起，用 * 运算符重复。
  • 单引号和双引号没区别
  • Python 中的字符串有两种索引方式，从左往右以 0 开始，从右往左以 -1 开始。
  • Python 没有单独的字符类型，一个字符就是长度为 1 的字符串。
  • 字符串切片：str[start:end:step] 其中 start（包含）是切片开始的索引，end（不包含）是切片结束的索引。
  • print输出默认是换行，不换行需要在变量末尾加上 end=””
  • Python 3 中整数字面量不允许前导零（如 080），八进制数必须使用 0o 前缀（如 0o17），十六进制使用 0x 前缀（如 0x69），二进制使用 0b 前缀。

Ch1 函数

  • python中的name意味着变量，可以随时和值绑定，在赋值语句中，会先执行等号右侧的值，然后依次从左到右赋值给左侧的变量

  • 赋值的时候内置函数也可以被赋值，变量也可以被赋值为函数，f=max，之后还可以继续f=1，重新赋值为常量

  • 一个语句可以同时给多个变量赋值，从左到右的顺序依次赋值

  • 代码语句只是被执行做出改变

  • print是个函数，它的返回值是none，但是它会有副作用会打印出东西

  • 所谓函数就是把名称绑定在一组运算上。def中写的参数是形式参数，只是提供一个名称为后续提供一个赋值的容器。

  • The name of a function is repeated twice, once in the frame and again as part of the function itself. The name appearing in the function is called the intrinsic name. The name in a frame is a bound name.

  • function signature指的是函数形式参数的描述。形式参数的个数是固定的，传入的时候不能随意更改。但是内置函数的参数个数是没有被定义的，所以传入参数个数是不定的

  • 定义函数的时候并不等于被执行，单独一步是进行整个函数的定义，但是没有被代入具体的值进行运算

  • 注意区分函数返回值并不是绑定在函数名称上的

  • 框架分为全局框架和局部框架，整个函数名称是全局框架，只有调用函数传入真实参数的时候才是创建局部框架

  • 每个函数被调用的时候都是会新创建一个环境

  • 函数的形式参数的名称仅仅作用于函数内部，每个函数的参数都是独立的

  • 函数使用看清定义域、值域、主体范围

  • 函数定义通常包括描述该功能的文档，称为 _docstring_，必须与函数主体一起缩进。文件字符串通常用三引号。第一行用一行描述了该函数的工作。

  • 在函数定义中，可以给其中一个参数赋值为常数，如果实际调用没有给出具体值，就按照定义时的常数去计算，提供的话就忽略定义给的常数、

  • 一些永不变化的值，如基本常数 k ，可以被束缚在函数体或全局参考系中。

  • 每条语句都描述了解释器（interpreter）状态的一种变化，执行语句就是把这种变化真正应用到解释器中。

  • statement是语句，是被执行使解释器状态发生改变的语句。expression是表达式，是计算出最终值的。解释器状态就是当前python中记住的东西

  • return 后面的表达式不会在定义函数时立即求值，而是会被保存起来，等到以后真正调用这个函数时才进行计算。

  • 函数定义时写def的时候只是建立函数对象，没有执行，return语句也没有被执行，只是被保存起来，等到调用的时候再执行

  • 函数体内部的赋值语句不会影响全局帧

  • 一个表达式如果被 Python 用来判断真假，而不是获取它的实际值，那么它就在布尔上下文中。

  • 三个基本的逻辑运算符：and/or/not 可以用作bool 运算。一个逻辑表达式的真假值，有时可以在不计算所有子表达式的情况下确定。

  • 布尔表达式的实际执行顺序是从左到右，比如说是and操作，如果左侧的表达式结果为false，那么就不会执行右侧表达式直接判断为false，反之结果就是右侧表达式的结果。注意这种逻辑表达式返回值不一定是布尔值，为左侧或者右侧表达式的真实值。

  • 右侧 = 后面的所有表达式，会先全部计算完成，然后才进行左侧变量的重新绑定。

  • 循环语句的最后循环条件的变量值一定得改变不然会变成无限循环。在每一次执行中改变某些变量，使条件最终可能变成 False。

  • 环境就是一个或者多个frame,每次调用一个函数就是创建一个新的frame，frame决定了查询的顺序，global是最后查询的，这个解释了为什么当变量名一样时函数内部的优先级会高于全局变量。

  • 通过高阶函数，我们开始看到一种更强大的抽象：某些函数能够表达通用的计算方法，而独立于它们所调用的具体函数。 但是缺点是全局环境帧（global frame）会变得拥挤不堪，塞满了各种小函数的名称，而且这些名称还必须互不相同。

  • 一般函数return结束后就会被内存回收消失，但是如果返回值是一个函数又被重新赋值给新的变量，那么这个局部函数就不会消失。

  • 函数curry。相同效果之下，一个函数接收多个参数返回一个值，和一个函数接收单个参数返回一个函数。所谓curry就是把传入多个参数的函数转化为只传入一个参数的函数，但是实现的效果是一样的。每次调用函数时，固定一个参数，并返回一个新的函数；这个新函数通过闭包保存之前已经固定的参数，等待剩余参数。

Ch2：Data

  • 数据抽象的关键是分离数据的表达方式和操作数据的方式。就是一种wishful thinking，假设一些函数成立，那么接下来的逻辑操作代码就可以简洁的书写。具体数据的实现方式可以不同，但是程序使用数据时不直接依赖这些实现细节，而是通过统一的抽象接口来操作。每个功能模块负责自己的部分，使数据表示和程序逻辑分离。
  • 最经典的例子就是有理数的表示。按照分子分母分开的方式分别进行计算，但是并不考虑怎么分离的分子分母，只是假定已经分离的函数是正确的。最后只是确认分离函数的实现方式
  • 任何有理数的表示可以按照分子、分母的方式来表示
  • from fractions import gcd python的库中直接由gcd可以算出两个整数的最大公约数
  • 数据抽象的核心思想是：针对某类值的所有操作，确定一组基本操作来表达它们，然后在处理数据时只使用这些操作。通过这种方式限制操作的使用范围，在不改变程序行为的前提下，更改抽象数据的表示方式将变得容易得多。所以就是把考虑操作方式和数据的表达方式的具体实现方式分开考虑计算。

  • list列表是python内置的原生数据类型。本质是一种任意长度的序列。内置的len()函数可以返回序列的长度。列表中的元素类型是任意的，可以列表嵌套列表，采用多次引用索引进行选取元素
  • 两种迭代循环方式，while和for。for语句的遍历方式可以直接遍历序列中的元素，无需引入新的变量。while遍历需要引入新的变量名进行遍历。每次for语句执行完之后，name会被绑定在序列中最后一个元素
  • 链表是由嵌套的对构成的，序列中第一个元素是当前节点值，第二个元素也是个序列链表。它的递归结构是第二个元素都是一个链表或者empty。要证明链表也是序列就要满足序列的两大特点，有长度且能进行元素选择，这个可以通过构造函数来实现此功能
  • 为数据添加状态，是一种称为面向对象编程的范式的核心要素。
  • 关于函数和对象，函数执行操作，数据是操作的对象。但是函数也可以像数据一样被操作，作为参数或者返回值被调用计算。

  • 许多解释器具有一种优雅的共同结构：两个相互递归的函数。第一个在环境中求值表达式；第二个将函数应用于参数。
  • 高级语言、编译语言、机器语言（01串）
  • 它采用与 Python 非常相似的计算模型，但仅使用表达式（没有语句），专注于符号计算，并且仅使用不可变值。
  • scheme中的海龟绘图，一只海龟在画布上有两个参数，一个是position，一个是heading方向，begin（）函数是按顺序执行传入的多个表达式参数，一个函数调用需要有一个整体的表达式，begin的返回值是最后一个表达式的值。
  • repeat k fn 意思是把fn函数执行k次，说明在这里函数也可以作为一个参数传入
  • 鲁棒性意思是抗折腾能力，一个系统面对变化异常的时候，仍然能够正常工作，不容易崩掉的能力。代码越少依赖具体实现、越依赖抽象接口，通常越鲁棒。
  • 引发异常是一种中断程序正常执行流程的技术，用于指示某种异常情况已经发生，并直接返回到程序中指定用于应对该情况的封闭部分。
  • Python 解释器每次在表达式或语句中检测到错误时都会引发异常。用户也可以通过 raise 和 assert 语句引发异常。
  • An exception is a object instance with a class that inherits, either directly or indirectly, from the BaseException class.一般来说，任何异常实例都可以通过 raise 语句引发。raise 最常见的用法是构造一个异常实例并引发它。>>> raise Exception(‘An error occurred’)
  • 异常可以由一个外层的 try 语句来处理。一个 try 语句由多个子句组成；第一个子句以 try 开头，其余子句以 except 开头
  • 用 Python 为 Calculator 语言实现一个解释器：
    • 我们将编写一个 Python 程序，它接收字符串行作为输入，并返回将这些行作为 Calculator 表达式求值的结果。如果计算器表达式格式不正确，我们的解释器将抛出适当的异常。
    • 加法和乘法接收任意数量的参数进行运算
    • 减法有两种行为，如果只传入一个参数则对这个参数取反。传入至少两个参数，则用第一个参数减去后面所有参数
    • 除法也是两种行为。一个参数就取倒数。多个参数就用第一个参数除以后面所有参数
  • 调用表达式是一个 Scheme 列表，其第一个元素（运算符）后面跟着零个或多个操作数表达式。
  • 装饰器就是“接收一个函数，再返回一个经过加工的新函数”。利用高阶函数，在不直接修改原函数代码的情况下，给函数增加功能。
