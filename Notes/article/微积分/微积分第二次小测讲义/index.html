微积分第二次小测讲义

微积分/微积分第二次小测讲义.md

模块一：极限、连续、偏导数与可微性的关系

这是最容易出现概念判断题（如多选题）的重灾区 。必须牢记它们之间的单向推导链条与反例陷阱。

1. 核心推导关系

  • 偏导数连续 $\Rightarrow$ 可微 $\Rightarrow$ 连续 $\Rightarrow$ 极限存在。

  • 可微 $\Rightarrow$ 偏导数存在 且 沿任意方向的方向导数存在。

2. 常见反例与易错点

  • 偏导数存在 $\nRightarrow$ 连续：例如只在坐标轴上有非零值，其余全为 $0$ 的函数，在原点偏导数存在但显然不连续。

  • 连续 $\nRightarrow$ 偏导数存在：例如包含绝对值或根号的函数（类似一元函数 $y=|x|$ 在原点的尖点）。

  • 方向导数存在 $\nRightarrow$ 可微/连续：即使沿所有直线的方向导数都存在，函数在原点也可能不可微 。

3. 分段函数在 $(0,0)$ 处的判定套路

面对 $f(x,y) = \frac{x^my^n}{x^a+y^b}$ 类的分段函数 ：

  1. 求偏导：必须使用定义法 $f_x’(0,0) = \lim_{x \to 0} \frac{f(x,0) - f(0,0)}{x}$。

  2. 判可微：计算全微分增量极限 $\lim_{\rho \to 0} \frac{\Delta z - (A\Delta x + B\Delta y)}{\sqrt{\Delta x^2 + \Delta y^2}}$。通常采用路径法（令 $y=kx$ 或 $y=x^2$）来证明极限不存在或不为 $0$，从而判定不可微 。

  3. 求方向导数：若不可微，必须使用定义法 $\lim_{t \to 0^+} \frac{f(t\cos\alpha, t\sin\alpha) - f(0,0)}{t}$ 。

模块二：多元复合函数与隐函数微分法

1. 链式求导法则

  • 核心法则：画出变量依赖树状图，分清“对第几个中间变量求导”与“最终对自变量求导”。

  • 常见题型：如 $\varphi(x) = f(x, f(2x-1, x^3))$，求导时要注意外层函数对第二个变量求导后，还需乘以内层函数的链式导数 。

2. 隐函数求导

  • 隐函数存在定理与公式：对于方程 $F(x,y,z)=0$ 确定的隐函数 $z=z(x,y)$，有 $\frac{\partial z}{\partial x} = -\frac{F_x’}{F_z’}$ 。

  • 实战技巧（全微分法）：遇到复杂的隐函数方程（如含有指数 $e^{2z}$ ），可直接对方程两边同时取微分操作 $d$，整理提取出 $dx$ 和 $dy$ 的系数，即为偏导数。

模块三：方向导数与梯度

1. 梯度（Gradient）

  • 定义：梯度是一个向量，指明了函数在某点增长最快的方向，即 $\text{grad},f = (f_x’, f_y’, f_z’)$ 。

2. 方向导数

  • 计算公式（可微条件）：沿单位方向向量 $\vec{l} = (\cos\alpha, \cos\beta, \cos\gamma)$，方向导数为梯度与该方向向量的内积，即 $\frac{\partial f}{\partial l} = \text{grad},f \cdot \vec{l}$。

  • 极值性质：函数沿梯度方向的方向导数最大，最大值等于梯度的模长 $|\text{grad},f|$ 。

模块四：空间几何应用

1. 空间曲面的切平面与法线

  • 法向量：对于隐式曲面 $F(x,y,z)=0$，其在某点的法向量为 $\vec{n} = (F_x’, F_y’, F_z’)$ 。

  • 切平面方程：点法式方程 $F_x’(x-x_0) + F_y’(y-y_0) + F_z’(z-z_0) = 0$ 。

2. 空间曲线的切线与法平面

  • 切向量：若曲线为参数方程 $r(t) = {x(t), y(t), z(t)}$，其切向量 $\vec{s} = {x’(t), y’(t), z’(t)}$ 。

  • 平行/垂直条件：曲线切线平行于某平面，意味着切向量 $\vec{s}$ 与平面的法向量 $\vec{n}$ 垂直，即 $\vec{s} \cdot \vec{n} = 0$ 。

模块五：极值问题与泰勒公式应用

1. 利用泰勒展开式提取偏导数

这是试卷中极为高频的“秒杀”技巧 。 若已知 $f(x,y) = A + B(x-x_0) + C(y-y_0) + D(x-x_0)^2 + E(x-x_0)(y-y_0) + F(y-y_0)^2 + o(\rho^2)$：

  • 函数值：$f(x_0,y_0) = A$。

  • 一阶偏导（全微分）：$f_x’ = B$，$f_y’ = C$。全微分为 $dz = Bdx + Cdy$ 。

  • 二阶偏导：注意泰勒展开二次项前的系数 $\frac{1}{2!}$。因此 $f_{xx}’’ = 2D$，$f_{xy}’’ = E$，$f_{yy}’’ = 2F$。

2. 极值判别法

  • 必要条件：若在内部取得极值，必为驻点（$f_x’ = 0$ 且 $f_y’ = 0$）。

  • 充分条件（Hessian矩阵）：令 $A = f_{xx}’’$，$B = f_{xy}’’$，$C = f_{yy}’’$。

    • $\Delta = AC - B^2 > 0$ 有极值（$A>0$ 极小，$A<0$ 极大）。

    • $\Delta = AC - B^2 < 0$ 无极值（鞍点）。

模块六：重积分的计算法宝

重积分计算的第一步永远是画图看对称性，切忌盲目硬算。

1. 对称性（奇偶性与轮换性）

  • 奇偶对称性：若积分区域关于坐标面（如 $x=0$）对称，且被积函数关于该变量（$x$）是奇函数，则积分为 $0$ 。

    • 例如_：$\iiint{x^2+y^2+z^2 \le 1} (2x+xy+z^2)dV$，因区域对原点和坐标面对称，$2x$ 和 $xy$ 均为奇函数，积分直接抵消为 $0$，只需算 $\iiint z^2 dV$ 。

  • 轮换对称性：若积分区域关于 $y=x$ 对称，则 $\iint_D f(x,y)d\sigma = \iint_D f(y,x)d\sigma$。

2. 分块法（处理绝对值与最值函数）

  • 遇到 $\iint \max(x,y) d\sigma$ 或 $\iint \sin(\min(x,y)) d\sigma$ 时，立即在积分区域内画出直线 $y=x$，将区域切分为 $y>x$ 和 $x>y$ 两部分，分别脱去 $\max/\min$ 符号后再积分 。

3. 坐标系转换

  • 看到 $x^2+y^2$，首选极坐标（二重积分）或柱坐标（三重积分）。

  • 看到 $x^2+y^2+z^2$，首选球面坐标。注意雅可比行列式的补偿（极坐标为 $rdrd\theta$）。

多元微积分期中/期末冲刺讲义

模块一：多元函数的基本概念（极限、连续、偏导、可微）

这是历年小测中最常考的理论辨析题，通常以选择题（多选）的形式出现。

1. 核心理论关系（必考概念图）

根据讲义中的逻辑关系图，你需要牢记以下推导链条：

  • 强条件 $\Rightarrow$ 弱条件：偏导数连续 $\Rightarrow$ 可微。
  • 可微 $\Rightarrow$ 必然满足的三个推论：若函数在某点可微，则必然连续、偏导数存在、沿任意方向的方向导数存在。
  • 易错反例：连续不一定可偏导；偏导数存在不一定连续；极限存在不一定连续（除非等于该点函数值）。

2. 分段函数在原点的性质辨析

  • 常见题型：给定含有分母为 $\sqrt{x^2+y^2}$ 或类似形式的分段函数，求其在 $(0,0)$ 处的偏导数或沿特定方向的方向导数。
  • 解题方法：必须使用定义法！
    • 求偏导：$f_x(0,0) = \lim_{\Delta x \to 0} \frac{f(\Delta x, 0) - f(0,0)}{\Delta x}$。
    • 求方向导数：使用极限公式 $\lim_{\rho \to 0^+} \frac{f(\rho\cos\theta, \rho\sin\theta) - f(0,0)}{\rho}$。
  • 拓展：注意判断 $\lim_{(x,y)\to(0,0)}$ 是否存在时，常用 $y=kx$ 或极坐标 $x=r\cos\theta, y=r\sin\theta$ 代入，若结果受 $k$ 或 $\theta$ 影响，则极限不存在。

模块二：偏导数计算与全微分

1. 复合函数求导（链式法则）

  • 常见题型：设 $\varphi(x) = f(x, f(2x-1, x^3))$，求 $\varphi’(1)$。
  • 解题方法：画出变量依赖树状图。由外向内逐层求导，注意不要漏掉中间变量。 $\varphi’(x) = f_1’ \cdot 1 + f_2’ \cdot [f_1’ \cdot 2 + f_2’ \cdot 3x^2]$，然后代入具体数值计算即可。

2. 基于泰勒展开（局部近似）判断全微分

  • 常见题型：已知函数在点 $P(0,1)$ 处满足 $f(x,y) = 5 + x - y + x^2 + 2x(y-1) + (y-1)^2 + o(…)$，求 $f(0,1)$、全微分 $df|_{(0,1)}$ 或判断极值。
  • 解题方法：对比二元函数泰勒展开式。
    • 常数项即为 $f(0,1) = 5$。
    • 一次项系数对应一阶偏导数：$f_x = 1, f_y = -1$，因此全微分 $df|_{(0,1)} = dx - dy$。
    • 二次项系数对应二阶偏导数（注意泰勒公式中有 $\frac{1}{2}$ 系数）。

模块三：几何应用（切线与切平面）

1. 空间曲线的切线

  • 常见题型：在空间曲线 $r(t) = {t, -t^2, t^3}$ 的所有切线中，寻找与平面 $x+2y+z=4$ 平行的切线。
  • 解题方法：
    1. 对参数方程求导得到切向量 $\vec{v} = r’(t) = {1, -2t, 3t^2}$。
    2. 提取目标平面的法向量 $\vec{n} = {1, 2, 1}$。
    3. 利用“线面平行 $\Leftrightarrow$ 方向向量与法向量垂直”的性质，令内积 $\vec{v} \cdot \vec{n} = 0$，解出 $1 - 4t + 3t^2 = 0$，得到两个 $t$ 的值，说明有两条切线。

2. 隐函数曲面的切平面

  • 常见题型：求曲面 $e^{2z} - xyz = e^2$ 在点 $M(0,2,1)$ 处的切平面方程。
  • 解题方法：构造隐函数 $F(x,y,z) = e^{2z} - xyz - e^2 = 0$。求梯度向量 $\nabla F = (F_x, F_y, F_z)$ 作为平面的法向量，代入点斜式即可。

模块四：方向导数与梯度

  • 常见题型：函数 $u = \sqrt{x^2+2y^2+3z^2}$ 在点 $M(2,-1,1)$ 处的梯度或最大方向导数。
  • 解题方法：
    1. 最大方向导数 = 梯度的模。先分别求出 $u_x, u_y, u_z$。
    2. 代入已知点 $M$ 得到梯度向量 $\nabla u = {u_x(M), u_y(M), u_z(M)}$。
    3. 取模 $|\nabla u|$ 即为最大方向导数的值（选项常为 $\frac{\sqrt{17}}{3}$）。
  • 拓展：如果题目要求“沿特定向量 $\vec{l}$ 的方向导数”，则需计算 $\nabla u \cdot \frac{\vec{l}}{|\vec{l}|}$（切记向量必须单位化）。

模块五：多元函数极值

  • 常见题型：隐函数极值判定或多项式极值判定。
  • 解题方法：
    1. 必要条件：驻点处 $f_x = 0, f_y = 0$。
    2. 充分条件：求出二阶偏导数 $A = f_{xx}, B = f_{xy}, C = f_{yy}$。
    3. 根据判别式 $\Delta = AC - B^2$ 判断：
      • $\Delta > 0$ 且 $A > 0$，为极小值。
      • $\Delta > 0$ 且 $A < 0$，为极大值。
      • $\Delta < 0$，无极值。
  • 拓展：若结合前面的泰勒展开题型，可通过直接提取二次项系数判断 $A, B, C$，从而快速判定 $(0,1)$ 点是否为极值点。

模块六：重积分计算

这是测试中计算量最大的部分，掌握“取巧”方法是关键。

1. 利用对称性化简重积分（必考）

  • 常见题型：已知 $\Omega: x^2+y^2+z^2 \le 1$，求 $\iiint_\Omega (2x + xy + z^2) dV$。
  • 解题方法：观察积分域，积分域关于原点或坐标轴高度对称。由于 $2x$ 和 $xy$ 是奇函数，在对称域上的积分为 $0$。原式直接化简为 $\iiint_\Omega z^2 dV$。
  • 拓展计算：利用轮换对称性，$\iiint z^2 dV = \frac{1}{3} \iiint (x^2+y^2+z^2) dV$，结合球坐标系轻松秒杀，答案为 $\frac{4}{15}\pi$。

2. 含 Max/Min 或绝对值的分段积分

  • 常见题型：$\iint_D e^{\max{x,y}} dxdy$，区域为 $0 \le x \le 1, 0 \le y \le 1$；或 $\iint_D \sin(\min(x,y)) dxdy$。
  • 解题方法：画图分块！ 在正方形区域内，画出对角线 $y=x$。
    • 在 $D_1$（$y>x$ 区域），$\max{x,y} = y$，积分变为 $\iint_{D_1} e^y dxdy$。
    • 在 $D_2$（$x>y$ 区域），$\max{x,y} = x$，积分变为 $\iint_{D_2} e^x dxdy$。 分别计算两个三角形区域的积分后相加。

3. 极坐标系下的双重积分

  • 常见题型：区域为 $x^2+y^2 \le 2|x| + |y| \ge 1$ 形式的计算。
  • 解题方法：统一替换 $x = r\cos\theta, y = r\sin\theta$，并将面积微元 $dxdy$ 替换为 $r dr d\theta$ 进行求解。

一、 分段函数在原点 $(0,0)$ 处的“全面体检”

这类题目（如测试卷中的多选题）往往给出一个含有分母 $x^2+y^2$ 的分段函数，要求判断其在原点的连续性、偏导数、可微性以及方向导数。

相关知识：

  • 连续：二重极限 $\lim_{(x,y)\to(0,0)} f(x,y) = f(0,0)$。

  • 偏导数：坐标轴方向的变化率。

  • 可微：全微分增量极限为 $0$。

  • 方向导数：任意射线方向的变化率。

解题技巧（严格遵循三步法）：

遇到此类题目，切忌直接使用求导公式，必须用定义！

  1. 求偏导用单变量极限：

    $$f_x’(0,0) = \lim_{x \to 0} \frac{f(x,0) - f(0,0)}{x}$$

    $$f_y’(0,0) = \lim_{y \to 0} \frac{f(0,y) - f(0,0)}{y}$$

  2. 判可微用路径法（证伪神器）：

    计算极限 $\lim_{(x,y) \to (0,0)} \frac{f(x,y) - f(0,0) - f_x’(0,0)x - f_y’(0,0)y}{\sqrt{x^2+y^2}}$。

    _技巧_：令 $y=kx$（直线逼近）或 $y=x^2$（抛物线逼近）代入上式。如果算出的结果含有 $k$，或者不等于 $0$，则立刻判定为不可微。

  3. 求方向导数用射线参数方程：

    设方向 $\vec{l} = (\cos\alpha, \sin\alpha)$。

    $$\frac{\partial f}{\partial l}\bigg|{(0,0)} = \lim{t \to 0^+} \frac{f(t\cos\alpha, t\sin\alpha) - f(0,0)}{t}$$

    _避坑_：千万不要用 $\text{grad},f \cdot \vec{l}$ 去算，因为这个公式仅在函数可微时成立。

二、 空间几何：切线、法面与平行的转化

几何应用题（如求切平面、切线方程，或已知平行/垂直关系求参数）是必考的计算题。

相关知识：

  • 曲面 $F(x,y,z)=0$ 的法向量：$\vec{n} = (F_x’, F_y’, F_z’)$。

  • 曲线 $r(t) = {x(t), y(t), z(t)}$ 的切向量：$\vec{s} = (x’(t), y’(t), z’(t))$。

解题技巧（几何关系的代数翻译）：

  1. 曲线切线 $\parallel$ 已知平面：

    • _翻译_：曲线的切向量 $\vec{s}$ 与平面的法向量 $\vec{n}$ 必须垂直。

    • _列式_：$\vec{s} \cdot \vec{n} = 0$。解这个方程就能找到对应的切点参数 $t$。

  2. 隐函数曲面求切平面（一招鲜）：

    • 遇到 $e^{2z} - xyz = e^2$ 这种方程，令 $F(x,y,z) = e^{2z} - xyz - e^2$。

    • 分别对 $x, y, z$ 求偏导，将已知点 $M(0,2,1)$ 代入得到法向量 $\vec{n} = (A, B, C)$。

    • 直接写出点法式：$A(x-0) + B(y-2) + C(z-1) = 0$。

三、 复合函数的高阶偏导数（链式法则的终极考验）

对于形如 $u = u(x, 2x)$ 求 $u_{xx}’’$ 的题目，极易在求导过程中漏项。

相关知识：

  • 多元复合函数的链式法则（树状图法）。

解题技巧（变量替换法）：

千万不要直接在原式上硬看，引入中间变量：

  1. 设中间变量：令 $v = x, w = 2x$，则 $u = u(v, w)$。

  2. 求一阶导：

    $$\frac{du}{dx} = \frac{\partial u}{\partial v}\frac{dv}{dx} + \frac{\partial u}{\partial w}\frac{dw}{dx} = u_1’ \cdot 1 + u_2’ \cdot 2$$

    (注：$u_1’, u_2’$ 表示对第1、第2个位置的变量求导)

  3. 求二阶导（算子法）：

    将 $\frac{d}{dx} = (\frac{\partial}{\partial v} \cdot 1 + \frac{\partial}{\partial w} \cdot 2)$ 作为一个算子，作用到一阶导数上：

    $$u_{xx}’’ = \frac{d}{dx}(u_1’ + 2u_2’) = (u_{11}’’ \cdot 1 + u_{12}’’ \cdot 2) + 2(u_{21}’’ \cdot 1 + u_{22}’’ \cdot 2)$$

    合并同类项（假设混合偏导数连续，$u_{12}’’ = u_{21}’’$）：

    $$u_{xx}’’ = u_{11}’’ + 4u_{12}’’ + 4u_{22}’’$$

四、 重积分的“降维打击”

重积分题目如果硬算原函数，往往会陷入死胡同。考试中的重积分题 80% 考查的是化简技巧。

相关知识：

  • 积分区域的对称性。

  • 极坐标、柱坐标、球面坐标系。

解题技巧：

  1. 奇偶对称性（第一眼必须看）：

    • 题目：$\iiint_{x^2+y^2+z^2 \le 1} (2x + xy + z^2) dV$。

    • _技巧_：球体关于 $x=0, y=0, z=0$ 全对称。看到 $2x$（关于 $x$ 是奇函数）、$xy$（关于 $x,y$ 是奇函数），直接划掉！积分瞬间退化为 $\iiint z^2 dV$。

  2. 绝对值与 $\max/\min$ 问题（切西瓜法）：

    • 题目：$\iint_D \sin(\min{x,y}) dxdy$，其中 $D$ 为正方形 $[0,\pi] \times [0,\pi]$。

    • _技巧_：画出正方形，再画对角线 $y=x$。这条线把正方形切成两半。

      • 在上方区域 $D_1$：$y > x$，所以 $\min{x,y} = x$。

      • 在下方区域 $D_2$：$y < x$，所以 $\min{x,y} = y$。

    • 然后利用轮换对称性，$2 \iint_{D_1} \sin x ,dxdy$ 即可快速解出。

  3. 累次积分的逆向操作（画图法）：

    • 题目：$\int_0^2 dx \int_0^{\sqrt{4-x^2}} \sqrt{x^2+y^2} dy$。

    • _技巧_：看到这种形式，绝对不要试图直接积分。先根据上下限画出积分区域（这是一个第一象限的四分之一圆）。一旦画出图形，立刻转换为极坐标：$\int_0^{\pi/2} d\theta \int_0^2 r \cdot r dr$，心算即可出结果。

五、 极值与泰勒展开的“读参法”

在之前的测试卷中出现了给出一个长长的多项式加上 $o(\rho^2)$，问你原点是不是极值点的题目。

相关知识：

  • 二元泰勒公式。

  • 极值的二阶充分条件 ($AC-B^2$)。

解题技巧（直接读系数）：

不要去求导！直接对比标准泰勒公式：

$$f(x,y) = f(x_0,y_0) + f_x’\Delta x + f_y’\Delta y + \frac{1}{2}(f_{xx}’’\Delta x^2 + 2f_{xy}’’\Delta x \Delta y + f_{yy}’’\Delta y^2) + o(\rho^2)$$

  • 一次项的系数就是一阶偏导数。如果一次项系数不全为 $0$，说明该点不是驻点，绝对没有极值！

  • 如果是驻点（一次项都没了），去读二次项系数：

    • $A = 2 \times (x^2\text{的系数})$

    • $B = xy\text{的系数}$

    • $C = 2 \times (y^2\text{的系数})$

  • 最后算 $AC - B^2$ 判别极值。这种方法在选择题中可以做到 10 秒出答案。
