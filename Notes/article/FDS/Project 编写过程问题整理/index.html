3.写测试的时候用的表格

Typst 表格解密

Typst 的表格其实就是个“流水线”。你只要掌握以下 4 个核心要素，以后任何表格闭着眼睛都能写出来：

核心要素一：columns (划定几列，每列多宽)

这是表格的灵魂。在 Typst 里，你给 columns 传几个参数，表格就有几列。

  • 绝对宽度：columns: (20pt, 50pt, 100pt) （不推荐，容易超出页面）。

  • 自动宽度：columns: (auto, auto, auto) （它会根据你字数的多少自动撑开）。

  • 魔法单位 fr (Fraction，比例)：强烈推荐！ 就像切蛋糕一样。比如 columns: (1fr, 2fr, 1fr)，意思是有三列，中间那列的宽度是两边列的 2倍。它会自动填满页面的宽度，永远不会越界！

核心要素二：align (对齐方式)

  • 默认情况下，文字都是靠上对齐的。

  • 如果你想让文字在格子里垂直居中，直接写：align: horizon。

  • 如果你想让文字居中且垂直居中：align: center + horizon。

核心要素三：[...] (填入内容)

Typst 没有像 Markdown 那样的 |---|---| 分隔符。它的逻辑是“傻瓜式数数”。 如果你规定了 columns 是 6 列，那么你往里面填的：

  • 第 1~6 个 [...] 就是第一行（通常是表头）。

  • 第 7~12 个 [...] 自动变成第二行。

  • 以此类推……**记得每个 [...] 后面一定要加逗号 ,**！

核心要素四：单元格内换行 (神仙快捷键 \)

在普通的 Markdown 里，要在表格的一个格子里换行简直是噩梦。但在 Typst 里，你只需要在 [...] 里敲一个反斜杠 \ 加空格，它就会强制换行！

  • 比如：[第一行 \ 第二行 \ 第三行]

3. 你的“写表心法” (Future Cheat Sheet)

以后你写报告遇到要画表格，直接在脑子里过这三步：

  1. 数一数要几列？（比如 3 列）。

  2. 哪列内容最多？（给内容多的列分配大一点的 fr，比如 (1fr, 3fr, 1fr)）。

  3. 开始填格子！（用 [...] 填，按顺序填，满 3 个自动换行，格子内部换行用 \）。

align(对齐方式)：

  • horizon ：垂直居中对齐
  • center：居中（只用center是居中和靠上）
  • left:靠左
  • right:靠右
  • top:靠上
  • bottom:靠下
  • 组合使用：
    • center+horizon:水平居中+垂直居中
    • right+bottom:靠右+靠下

表头固定 (Header) —— 跨页不迷路

如果你的测试用例很多，表格被挤到了第二页，第二页就没有表头了。 使用 table.header() 可以告诉 Typst 哪些是表头，换页时它会自动在第二页顶部再印一遍表头。

背景填色 (Fill) —— 斑马线效果

为了防止看串行，可以给表头加浅灰色背景，或者给表格加上“斑马线”。

  • 比如设置表头的背景：fill: luma(230)（浅灰色）。
