3.1 二元离散型随机变量

本节导读

PPT 顺序： 联合概率分布 → 边际分布 → 条件分布。
PPT 主要对应第 5—28 页；教材对应第 81—86 页。
老师讲稿思路（约 00:07—00:11）： 先把每一对 \((x_i,y_j)\) 的同时概率列出来，再按行、按列求和得到边际分布；条件分布则是在联合概率的基础上除以条件事件的边际概率。

一、二元随机变量与联合分布律

1. 定义

设 \(X=X(e)\)、\(Y=Y(e)\) 是定义在同一样本空间上的两个随机变量。由它们组成的有序对 \((X,Y)\) 称为二元随机变量（Bivariate Random Variable）。

若 \((X,Y)\) 的可能取值只有有限个或可列无限个，则称它为二元离散型随机变量。

2. 联合概率分布律

设 \((X,Y)\) 的可能取值为 \((x_i,y_j)\)，定义

\[\boxed{p_{ij}=P(X=x_i,Y=y_j).}\]

\(p_{ij}\) 描述 \(X=x_i\) 与 \(Y=y_j\) 同时发生的概率。

联合分布律满足：

\[\boxed{p_{ij}\ge0}\]

以及

\[\boxed{\sum_i\sum_j p_{ij}=1.}\]

为什么总和等于 1？

所有可能的 \((X,Y)=(x_i,y_j)\) 取值事件互不相容，并且它们覆盖全部可能结果。根据互斥事件的概率加法公式，所有联合概率之和为 1。

3. PPT 例 1.1：先取 \(X\)，再根据 \(X\) 取 \(Y\)

\(X\) 在 \(1,2,3,4\) 中等可能地取一个值；给定 \(X=i\)，\(Y\) 在 \(1,\ldots,i\) 中等可能地取一个整数。求联合分布律。

因为 \(X\) 有 4 个等可能值，

\[P(X=i)=\frac14,\quad i=1,2,3,4.\]

给定 \(X=i\) 后，\(Y\) 在 \(i\) 个整数中等可能取值，所以

\[P(Y=j\mid X=i)=\frac1i,\quad j=1,\ldots,i.\]

利用乘法公式：

\[\begin{aligned} P(X=i,Y=j) &=P(X=i)P(Y=j\mid X=i)\\ &=\frac14\cdot\frac1i. \end{aligned}\]

因此

\[\boxed{ p_{ij}=\frac1{4i},\quad i=1,2,3,4,\quad 1\le j\le i. }\]

若 \(j>i\)，则 \(p_{ij}=0\)。例如：

\(X\backslash Y\) 1 2 3 4
1 \(1/4\) 0 0 0
2 \(1/8\) \(1/8\) 0 0
3 \(1/12\) \(1/12\) \(1/12\) 0
4 \(1/16\) \(1/16\) \(1/16\) \(1/16\)
易错点

不是所有格子都能取值。必须先看 \((X,Y)\) 的实际取值范围。

二、边际分布律

1. 定义与公式

已知联合分布律 \(p_{ij}\)，则 \(X\) 和 \(Y\) 的边际分布律分别为

\[\boxed{P(X=x_i)=p_{i\cdot}=\sum_j p_{ij}}\]
\[\boxed{P(Y=y_j)=p_{\cdot j}=\sum_i p_{ij}.}\]

记号说明：

  • \(p_{i\cdot}\)：固定 \(i\)，把第 \(i\) 行所有 \(j\) 的概率相加。
  • \(p_{\cdot j}\)：固定 \(j\)，把第 \(j\) 列所有 \(i\) 的概率相加。

2. 推导

对固定的 \(x_i\)，事件 \(\{X=x_i\}\) 可以分解成互不相容事件的并：

\[\{X=x_i\}=\bigcup_j\{X=x_i,Y=y_j\}.\]

所以

\[\begin{aligned} P(X=x_i) &=\sum_jP(X=x_i,Y=y_j)\\ &=\sum_jp_{ij}. \end{aligned}\]

同理，

\[P(Y=y_j)=\sum_iP(X=x_i,Y=y_j)=\sum_i p_{ij}.\]

这就是“边际化”的本质：把另一个变量的所有可能情况加起来。

3. PPT 例 1.2：吸烟与呼吸道疾病

令 \(X\) 表示吸烟程度：

  • \(X=0\)：不吸烟，概率 \(0.80\)；
  • \(X=1\)：少量吸烟，概率 \(0.15\)；
  • \(X=2\)：吸烟较多，概率 \(0.05\)。

令 \(Y=1\) 表示患病，\(Y=0\) 表示不患病。已知：

\[P(Y=1\mid X=0)=0.05,\]
\[P(Y=1\mid X=1)=0.25,\]
\[P(Y=1\mid X=2)=0.70.\]

利用

\[P(X=i,Y=1)=P(X=i)P(Y=1\mid X=i),\]

得到：

\[P(X=0,Y=1)=0.80\times0.05=0.04,\]
\[P(X=1,Y=1)=0.15\times0.25=0.0375,\]
\[P(X=2,Y=1)=0.05\times0.70=0.035.\]

再用每行的边际概率减去患病概率，得到不患病概率。

\(X\) \(Y=0\) 不患病 \(Y=1\) 患病 \(P(X=i)\)
0 0.7600 0.0400 0.80
1 0.1125 0.0375 0.15
2 0.0150 0.0350 0.05
\(P(Y=j)\) 0.8875 0.1125 1

求“患病人群中吸烟者的概率”：

\[\begin{aligned} P(X\in\{1,2\}\mid Y=1) &=\frac{P(X=1,Y=1)+P(X=2,Y=1)}{P(Y=1)}\\ &=\frac{0.0375+0.035}{0.1125}\\ &\approx\boxed{0.6444}. \end{aligned}\]
易错点

“吸烟者中患病的概率”与“患病者中吸烟的概率”是不同的条件概率，分母不同。

三、条件分布律

1. 定义与公式

若 \(P(Y=y_j)=p_{\cdot j}>0\)，则给定 \(Y=y_j\) 时，\(X\) 的条件分布律为

\[\boxed{ P(X=x_i\mid Y=y_j) =\frac{P(X=x_i,Y=y_j)}{P(Y=y_j)} =\frac{p_{ij}}{p_{\cdot j}}. }\]

同理，若 \(P(X=x_i)=p_{i\cdot}>0\)，则

\[\boxed{ P(Y=y_j\mid X=x_i)=\frac{p_{ij}}{p_{i\cdot}}. }\]

2. 推导

从条件概率定义出发：

\[P(A\mid B)=\frac{P(A\cap B)}{P(B)},\quad P(B)>0.\]

令 \(A=\{X=x_i\}\)、\(B=\{Y=y_j\}\)，便得到第一个公式。交换 \(X,Y\) 得到第二个公式。

3. 条件分布为什么仍是一个分布律？

固定 \(y_j\) 后，

\[P(X=x_i\mid Y=y_j)\ge0.\]

并且

\[\begin{aligned} \sum_iP(X=x_i\mid Y=y_j) &=\sum_i\frac{p_{ij}}{p_{\cdot j}}\\ &=\frac{\sum_i p_{ij}}{p_{\cdot j}}\\ &=1. \end{aligned}\]

所以条件概率满足分布律的非负性与归一化要求。

4. PPT 例 1.3：求未知概率及条件分布

联合分布表：

\(X\backslash Y\) \(-1\) 0 1
1 \(a\) 0.2 0.2
2 0.1 0.1 \(b\)

已知

\[P(Y\le0\mid X<2)=0.5.\]

因为 \(X<2\) 意味着 \(X=1\)，所以

\[0.5=\frac{a+0.2}{a+0.4}.\]

解得

\[a=0.\]

所有联合概率之和为 1：

\[a+b+0.6=1,\]

所以

\[\boxed{a=0,\quad b=0.4.}\]

接着求 \(Y\mid X=2\)。因为

\[P(X=2)=0.1+0.1+0.4=0.6,\]

所以

\[P(Y=-1\mid X=2)=\frac{0.1}{0.6}=\frac16,\]
\[P(Y=0\mid X=2)=\frac{0.1}{0.6}=\frac16,\]
\[P(Y=1\mid X=2)=\frac{0.4}{0.6}=\frac23.\]

若已知 \(X+Y=2\)，只有 \((X,Y)=(1,1)\) 与 \((2,0)\) 两种情况：

\[P(X+Y=2)=0.2+0.1=0.3.\]

于是

\[P(X=1\mid X+Y=2)=\frac{0.2}{0.3}=\frac23,\]
\[P(X=2\mid X+Y=2)=\frac{0.1}{0.3}=\frac13.\]
解题模板

先求条件事件的概率作为分母，再找同时满足目标条件的联合概率作为分子。

5. PPT 例 1.4：抽球，不放回与放回的区别

盒中有 3 只黑球、2 只红球、1 只白球，抽取 2 球。\(X\) 为黑球数，\(Y\) 为红球数。

不放回抽样

共有 \(\binom62=15\) 种等可能的两球组合。联合分布律为：

\(X\backslash Y\) 0 1 2 \(P(X=i)\)
0 0 \(2/15\) \(1/15\) \(1/5\)
1 \(3/15\) \(6/15\) 0 \(3/5\)
2 \(3/15\) 0 0 \(1/5\)
\(P(Y=j)\) \(6/15\) \(8/15\) \(1/15\) 1

例如，\(X=1,Y=1\) 意味着一黑一红，有 \(3\times2=6\) 种组合，所以概率为 \(6/15\)。

给定 \(X=1\)，有

\[P(Y=0\mid X=1)=\frac{3/15}{9/15}=\frac13,\]
\[P(Y=1\mid X=1)=\frac{6/15}{9/15}=\frac23.\]
放回抽样

每次抽球后放回。联合分布律为：

\(X\backslash Y\) 0 1 2 \(P(X=i)\)
0 \(1/36\) \(4/36\) \(4/36\) \(1/4\)
1 \(6/36\) \(12/36\) 0 \(1/2\)
2 \(9/36\) 0 0 \(1/4\)
\(P(Y=j)\) \(16/36\) \(16/36\) \(4/36\) 1

给定 \(Y=0\)，即没有红球：

\[P(X=0\mid Y=0)=\frac{1/36}{16/36}=\frac1{16},\]
\[P(X=1\mid Y=0)=\frac6{16},\qquad P(X=2\mid Y=0)=\frac9{16}.\]
对比

抽样机制不同，联合分布律也不同；列出联合概率时要先明确是否放回。

6. PPT 例 1.5：射击直到命中两次

每次射击命中概率为 \(p\)，未命中概率 \(q=1-p\)。\(X\) 为首次命中时的射击次数，\(Y\) 为第二次命中时的总射击次数。

若 \(Y=n\)，\(X=m\)，则前 \(m-1\) 次未命中、第 \(m\) 次命中；从第 \(m+1\) 到第 \(n-1\) 次未命中、第 \(n\) 次命中。因此

\[\boxed{P(X=m,Y=n)=p^2q^{n-2},\quad n>m\ge1.}\]

边际分布：

\[P(X=m)=\sum_{n=m+1}^{\infty}p^2q^{n-2} =pq^{m-1},\quad m\ge1.\]
\[P(Y=n)=\sum_{m=1}^{n-1}p^2q^{n-2} =(n-1)p^2q^{n-2},\quad n\ge2.\]

条件分布：

\[\boxed{P(Y=n\mid X=m)=pq^{n-m-1},\quad n=m+1,m+2,\ldots}\]
\[\boxed{P(X=m\mid Y=n)=\frac1{n-1},\quad m=1,\ldots,n-1.}\]

第二个结论说明：已知第二次命中发生在第 \(n\) 次时，第一次命中可能出现在前 \(n-1\) 次中的任何一次，而且这些位置等可能。

补充 1：7 个球中抽 3 次，不放回

袋中有 4 个白球、1 个红球、2 个黑球。抽 3 次不放回，\(X\) 为白球数，\(Y\) 为红球数。

黑球数必为 \(3-i-j\)，因此

\[\boxed{ P(X=i,Y=j)= \frac{\binom4i\binom1j\binom2{3-i-j}}{\binom73} }\]

其中组合数下标必须合法；不满足球数范围的组合概率为 0。

这个公式来自超几何计数：分母是从 7 球中选 3 球的总组合数，分子是分别选出 \(i\) 个白球、\(j\) 个红球、\(3-i-j\) 个黑球的组合数。

补充 2：泊松乘客中途下车（Poisson thinning）

乘客总数 \(X\sim P(\lambda)\)，每位乘客独立地以概率 \(p\) 在中途下车。令 \(Y\) 为中途下车人数。

给定 \(X=m\)，有

\[Y\mid X=m\sim B(m,p),\]

所以

\[\begin{aligned} P(X=m,Y=n) &=P(X=m)P(Y=n\mid X=m)\\ &=e^{-\lambda}\frac{\lambda^m}{m!} \binom mn p^n(1-p)^{m-n}. \end{aligned}\]

对 \(m\ge n\) 求和可得

\[\boxed{Y\sim P(\lambda p).}\]

而给定 \(Y=n\)，剩下未中途下车的乘客数 \(X-Y\) 服从 \(P(\lambda(1-p))\)，因此

\[\boxed{X\mid Y=n\ \overset{d}= n+P(\lambda(1-p)).}\]
补充 3：排列彩票的两次中奖时间

每期中奖概率 \(p=1/100\)，令 \(X\) 为第一次中奖期数，\(Y\) 为第二次中奖期数。对 \(1\le m<n\)，

\[P(X=m,Y=n)=p^2(1-p)^{n-2}.\]

给定 \(Y=n\)，有

\[\boxed{P(X=m\mid Y=n)=\frac1{n-1},\quad m=1,\ldots,n-1.}\]

3.2 二元随机变量的分布函数

本节导读

PPT 顺序： 联合分布函数及性质 → 边际分布函数 → 条件分布函数。
PPT 主要对应第 30—36 页；教材对应第 87—90 页。
老师讲稿思路（约 00:11—00:16）： \(F(x,y)\) 是随机点落在 \((x,y)\) 左下方区域的概率；把另一个坐标放到 \(+\infty\)，就不再限制那个变量，从而得到边际分布函数。连续型变量在单点上的概率为零时，条件分布要通过越来越薄的邻域取极限来理解。

一、联合分布函数

1. 定义

对于任意实数 \(x,y\)，定义

\[\boxed{F(x,y)=P(X\le x,Y\le y).}\]

它表示随机点 \((X,Y)\) 落入左下区域 \((-\infty,x]\times(-\infty,y]\) 的概率。

2. 主要性质

  1. 单调不减： 固定 \(y\)，\(F(x,y)\) 关于 \(x\) 单调不减；固定 \(x\)，关于 \(y\) 单调不减。

  2. 取值范围：

    \[0\le F(x,y)\le1.\]

  3. 极限：

    \[F(+\infty,+\infty)=1,\]
    \[F(-\infty,y)=F(x,-\infty)=0.\]

  4. 右连续： 对 \(x\) 或 \(y\) 单独改变时，分布函数具有相应的一维右连续性。

  5. 矩形增量非负： 若 \(x_1<x_2,\ y_1<y_2\)，则

    \[\boxed{ \begin{aligned} &P(x_1<X\le x_2,\ y_1<Y\le y_2)\\ &=F(x_2,y_2)-F(x_1,y_2)\\ &\quad-F(x_2,y_1)+F(x_1,y_1)\ge0. \end{aligned}}\]

3. 矩形概率公式的推导

先从 \(F(x_2,y_2)\) 中减去 \(F(x_1,y_2)\)，得到

\[P(x_1<X\le x_2,\ Y\le y_2).\]

再减去 \(F(x_2,y_1)-F(x_1,y_1)\)，就去掉了其中 \(Y\le y_1\) 的部分，只留下 \(y_1<Y\le y_2\)。因此得到矩形增量公式。

直观理解

用大矩形概率减去左侧与下侧不需要的部分，再加回被重复减去的左下角。

二、边际分布函数

1. 定义与公式

联合分布函数为 \(F(x,y)\)，则

\[\boxed{F_X(x)=P(X\le x)=F(x,+\infty)}\]
\[\boxed{F_Y(y)=P(Y\le y)=F(+\infty,y).}\]

2. 推导

\[\begin{aligned} F_X(x) &=P(X\le x)\\ &=P(X\le x,Y<+\infty)\\ &=\lim_{y\to+\infty}F(x,y). \end{aligned}\]

同理可得 \(F_Y(y)=\lim_{x\to+\infty}F(x,y)\)。

记忆

求 \(X\) 的边际分布函数，就让另一个变量 \(Y\) 趋于 \(+\infty\)；反之亦然。

三、条件分布函数

1. 离散情形

如果 \(P(X=x_i)>0\)，则

\[\boxed{F_{Y\mid X}(y\mid x_i)=P(Y\le y\mid X=x_i).}\]

它是一维条件分布函数，计算时使用条件概率公式。

2. 连续情形：为什么需要极限？

连续型随机变量通常满足 \(P(X=x)=0\)，不能直接使用以 \(P(X=x)\) 为分母的条件概率公式。

因此，PPT 和教材用越来越窄的区间逼近 \(X=x\)：

\[\boxed{ F_{Y\mid X}(y\mid x) =\lim_{\Delta x\to0^+} P(Y\le y\mid x<X\le x+\Delta x). }\]

写成概率之比：

\[F_{Y\mid X}(y\mid x) =\lim_{\Delta x\to0^+} \frac{P(Y\le y,\ x<X\le x+\Delta x)} {P(x<X\le x+\Delta x)}.\]

当相关极限存在且边际密度 \(f_X(x)>0\) 时，后续可以由这个定义推导出条件密度公式。

教材补充：无放回抽样的条件分布函数

教材用同一袋球中连续两次抽取的指示变量举例。若总共有 \(n=a+b\) 个球，其中 \(a\) 个白球、\(b\) 个红球，令 \(X_i\) 表示第 \(i\) 次是否抽到白球（白球记 1，红球记 0），不放回抽样时

\[P(X_i=1)=\frac an,\qquad P(X_i=0)=\frac bn.\]

对于 \(i\ne j\)，

\[P(X_i=1,X_j=1)=\frac{a(a-1)}{n(n-1)},\]
\[P(X_i=1,X_j=0)=P(X_i=0,X_j=1)=\frac{ab}{n(n-1)},\]
\[P(X_i=0,X_j=0)=\frac{b(b-1)}{n(n-1)}.\]

例如

\[P(X_j=1\mid X_i=1)=\frac{a-1}{n-1}.\]

第一次已抽到白球后，剩余白球比例变为 \((a-1)/(n-1)\)，这与原来的 \(a/n\) 一般不同。

3.3 二元连续型随机变量

本节导读

PPT 顺序： 联合密度 → 边际密度 → 条件密度 → 二元均匀分布 → 二元正态分布。
PPT 主要对应第 37—71 页；教材对应第 91—100 页。
老师讲稿思路（约 00:16—00:25、01:02—01:19）： 把联合密度看成曲面高度：全平面下的体积为 1，某个区域上方的体积就是概率；边际密度可以理解为固定一个坐标后，对另一坐标积分得到的截面积；条件密度则是把联合密度除以给定变量的边际密度。

一、联合概率密度函数

1. 定义

若存在非负函数 \(f(x,y)\)，使得对任意 \(x,y\)，

\[\boxed{ F(x,y)=\int_{-\infty}^{x}\int_{-\infty}^{y} f(u,v)\,dv\,du, }\]

则称 \((X,Y)\) 为二元连续型随机变量，\(f(x,y)\) 为联合概率密度函数（Joint Probability Density Function）。

2. 联合密度的性质

\[\boxed{f(x,y)\ge0}\]
\[\boxed{ \int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty} f(x,y)\,dx\,dy=1 }\]

对平面区域 \(G\)，

\[\boxed{ P((X,Y)\in G)=\iint_G f(x,y)\,dx\,dy. }\]

在联合分布函数具有相应偏导数、密度连续的点上，

\[\boxed{f(x,y)=\frac{\partial^2F(x,y)}{\partial x\,\partial y}.}\]

3. 为什么区域概率是二重积分？

在很小的面积 \(dx\,dy\) 附近，概率近似为 \(f(x,y)\,dx\,dy\)。把区域 \(G\) 划分成许多小块并将这些概率相加，极限就得到

\[P((X,Y)\in G)=\iint_G f(x,y)\,dx\,dy.\]

几何上，联合密度曲面 \(z=f(x,y)\) 在整个平面上的体积为 1；区域 \(G\) 上方的曲面体积就是 \((X,Y)\) 落在 \(G\) 内的概率。面积为零的集合在连续型二维分布下概率为零。

老师讲稿特别强调：密度不是点概率

  • \(f(x,y)\) 是点 \((x,y)\) 附近的概率密度，不是 \(P(X=x,Y=y)\)。

  • 对足够小的矩形，若密度在附近变化不大，则

    \[P(x<X\le x+\Delta x,\ y<Y\le y+\Delta y) \approx f(x,y)\Delta x\Delta y.\]

  • 若 \((X,Y)\) 具有联合密度，那么落在一条直线上的概率为 0。例如

    \[\boxed{P(Y=2X+4)=0.}\]

    因为这条直线在平面上的面积为 0，与具体密度函数的数值无关。

二、PPT 例 3.1：求归一化常数、联合分布函数与区域概率

给定

\[f(x,y)= \begin{cases} ke^{-(2x+3y)},&x>0,\ y>0,\\ 0,&\text{其他}. \end{cases}\]

（1）求 \(k\)

由全平面密度积分等于 1：

\[\begin{aligned} 1&=\int_0^\infty\int_0^\infty ke^{-(2x+3y)}\,dx\,dy\\ &=k\left(\int_0^\infty e^{-2x}dx\right) \left(\int_0^\infty e^{-3y}dy\right)\\ &=k\cdot\frac12\cdot\frac13. \end{aligned}\]

所以

\[\boxed{k=6.}\]

（2）求联合分布函数

当 \(x>0,y>0\) 时，

\[\begin{aligned} F(x,y) &=\int_0^x\int_0^y6e^{-(2u+3v)}\,dv\,du\\ &=\left(\int_0^x2e^{-2u}\,du\right) \left(\int_0^y3e^{-3v}\,dv\right)\\ &=(1-e^{-2x})(1-e^{-3y}). \end{aligned}\]

因此

\[\boxed{ F(x,y)= \begin{cases} (1-e^{-2x})(1-e^{-3y}),&x>0,y>0,\\ 0,&\text{其他}. \end{cases}}\]

（3）求 \(P(Y\le X)\)

区域为 \(0<y\le x\)，所以

\[\begin{aligned} P(Y\le X) &=\int_0^\infty\int_y^\infty 6e^{-(2x+3y)}\,dx\,dy\\ &=\int_0^\infty3e^{-3y}e^{-2y}\,dy\\ &=\int_0^\infty3e^{-5y}\,dy\\ &=\boxed{\frac35}. \end{aligned}\]
积分范围原则

先画出区域，确定固定外层变量后内层变量的取值范围。

三、PPT 例 3.2：非矩形定义域的联合密度

给定

\[f(x,y)= \begin{cases} cy,&0<x<1,\ x^2<y<x,\\ 0,&\text{其他}. \end{cases}\]

（1）求 \(c\)

\[\begin{aligned} 1&=\int_0^1\int_{x^2}^{x}cy\,dy\,dx\\ &=\frac c2\int_0^1(x^2-x^4)\,dx\\ &=\frac c2\left(\frac13-\frac15\right)=\frac c{15}. \end{aligned}\]

所以

\[\boxed{c=15.}\]

（2）求 \(P(X>0.5)\)

先求 \(X\) 的边际密度（下一节会推导一般公式）：

\[f_X(x)=\int_{x^2}^{x}15y\,dy =\frac{15}{2}(x^2-x^4),\quad 0<x<1.\]

于是

\[\begin{aligned} P(X>0.5) &=\int_{1/2}^{1}\frac{15}{2}(x^2-x^4)\,dx\\ &=\boxed{\frac{47}{64}}\approx0.7344. \end{aligned}\]

（3）求 \(P(Y\le0.5)\)

固定 \(y\)，由 \(x^2<y<x\) 可得

\[y<x<\sqrt y,\quad 0<y<1.\]

因此

\[\begin{aligned} P(Y\le0.5) &=\int_0^{1/2}\int_y^{\sqrt y}15y\,dx\,dy\\ &=\int_0^{1/2}15y(\sqrt y-y)\,dy\\ &=\boxed{\frac{6\sqrt2-5}{8}}\approx0.4357. \end{aligned}\]

（4）求 \(P(X>0.5,Y\le0.5)\)

条件 \(X>0.5\)、\(Y\le0.5\) 与原区域结合后，得到

\[\frac12<x<\frac1{\sqrt2},\qquad x^2<y<\frac12.\]

所以

\[\begin{aligned} P(X>0.5,Y\le0.5) &=\int_{1/2}^{1/\sqrt2}\int_{x^2}^{1/2}15y\,dy\,dx\\ &=\boxed{\frac{48\sqrt2-57}{64}}\approx0.1700. \end{aligned}\]

该结果不等于 \(P(X>0.5)P(Y\le0.5)\)，所以这道例题也说明 \(X,Y\) 不独立。

四、边际概率密度函数

1. 定义与公式

若联合密度为 \(f(x,y)\)，则

\[\boxed{f_X(x)=\int_{-\infty}^{+\infty}f(x,y)\,dy}\]
\[\boxed{f_Y(y)=\int_{-\infty}^{+\infty}f(x,y)\,dx.}\]

求 \(f_X(x)\) 时固定 \(x\)，对 \(y\) 积分；求 \(f_Y(y)\) 时固定 \(y\)，对 \(x\) 积分。

老师的切片理解

固定 \(x\) 后，沿着这条竖直切片把联合密度对所有允许的 \(y\) 加总，得到的就是 \(f_X(x)\)；固定 \(y\) 时则沿水平方向切片。积分范围不是永远从 \(-\infty\) 到 \(+\infty\) 都有贡献，而是要与联合密度的实际定义域相交。

2. 完整推导

由联合分布函数，

\[\begin{aligned} F_X(x) &=F(x,+\infty)\\ &=\int_{-\infty}^{x} \left[\int_{-\infty}^{+\infty}f(u,v)\,dv\right]du. \end{aligned}\]

定义

\[f_X(u)=\int_{-\infty}^{+\infty}f(u,v)\,dv,\]

便得到

\[F_X(x)=\int_{-\infty}^{x}f_X(u)\,du.\]

对 \(x\) 求导，根据变上限积分求导公式，

\[\boxed{\frac{dF_X(x)}{dx}=f_X(x) =\int_{-\infty}^{+\infty}f(x,y)\,dy.}\]

对称地可得 \(f_Y(y)\) 的公式。

3. PPT 例 3.3：延续例 3.2 求边际密度

原密度为 \(15y\)，区域 \(0<x<1,\ x^2<y<x\)。

固定 \(x\)：

\[\boxed{ f_X(x)= \begin{cases} \dfrac{15}{2}(x^2-x^4),&0<x<1,\\ 0,&\text{其他}. \end{cases}}\]

固定 \(y\)，积分范围是 \(y<x<\sqrt y\)：

\[\begin{aligned} f_Y(y)&=\int_y^{\sqrt y}15y\,dx\\ &=15y(\sqrt y-y). \end{aligned}\]

所以

\[\boxed{ f_Y(y)= \begin{cases} 15(y^{3/2}-y^2),&0<y<1,\\ 0,&\text{其他}. \end{cases}}\]
易错点

联合密度的定义域是弯曲区域时，边际密度的积分上下限可能依赖于固定变量。

五、条件概率密度函数

1. 公式

当 \(f_Y(y)>0\) 时，给定 \(Y=y\)，\(X\) 的条件密度为

\[\boxed{f_{X\mid Y}(x\mid y)=\frac{f(x,y)}{f_Y(y)}.}\]

当 \(f_X(x)>0\) 时，给定 \(X=x\)，\(Y\) 的条件密度为

\[\boxed{f_{Y\mid X}(y\mid x)=\frac{f(x,y)}{f_X(x)}.}\]

2. 从条件分布函数推导条件密度

以 \(f_{X\mid Y}(x\mid y)\) 为例。连续型变量通常有 \(P(Y=y)=0\)，所以先用窄区间 \(y<Y\le y+\Delta y\) 逼近 \(Y=y\)：

\[F_{X\mid Y}(x\mid y) =\lim_{\Delta y\to0^+} \frac{P(X\le x,\ y<Y\le y+\Delta y)} {P(y<Y\le y+\Delta y)}.\]

把分子写成联合密度积分：

\[P(X\le x,\ y<Y\le y+\Delta y) =\int_y^{y+\Delta y}\int_{-\infty}^{x}f(u,v)\,du\,dv.\]

分母写成边际密度积分：

\[P(y<Y\le y+\Delta y)=\int_y^{y+\Delta y}f_Y(v)\,dv.\]

于是

\[F_{X\mid Y}(x\mid y) =\lim_{\Delta y\to0^+} \frac{ \int_y^{y+\Delta y}\int_{-\infty}^{x}f(u,v)\,du\,dv }{ \int_y^{y+\Delta y}f_Y(v)\,dv }.\]

在相应连续性与极限条件下，分子、分母分别除以 \(\Delta y\) 后取极限，得到

\[\boxed{ F_{X\mid Y}(x\mid y) =\frac{\int_{-\infty}^{x}f(u,y)\,du}{f_Y(y)}. }\]

对 \(x\) 求导：

\[\begin{aligned} f_{X\mid Y}(x\mid y) &=\frac{\partial}{\partial x}F_{X\mid Y}(x\mid y)\\ &=\frac{1}{f_Y(y)} \frac{d}{dx}\int_{-\infty}^{x}f(u,y)\,du\\ &=\boxed{\frac{f(x,y)}{f_Y(y)}}. \end{aligned}\]

最后一步使用变上限积分求导公式。另一个条件密度公式通过交换 \(X,Y\) 的角色得到。

条件密度的直观理解：薄片上的条件概率

以给定 \(Y=y\) 为例。由于连续型变量通常满足 \(P(Y=y)=0\)，不能直接把单点事件当作普通条件概率的分母。老师讲稿的思路是先看薄片 \(y<Y\le y+\Delta y\)：

  • 分子是随机点落在一个小矩形里的概率，近似为 \(f(x,y)\Delta x\Delta y\)；

  • 分母是落在薄片里的概率，近似为 \(f_Y(y)\Delta y\)；

  • 两者相除后，\(\Delta y\) 约掉，剩下

    \[P(x<X\le x+\Delta x\mid Y\approx y) \approx \frac{f(x,y)}{f_Y(y)}\Delta x.\]

因此条件密度自然是

\[\boxed{f_{X\mid Y}(x\mid y)=\frac{f(x,y)}{f_Y(y)}}.\]

这个直觉也解释了为什么分母一定是已知条件变量的边际密度。

3. 条件密度的性质

以 \(f_{X\mid Y}\) 为例：

\[f_{X\mid Y}(x\mid y)\ge0,\]
\[\int_{-\infty}^{+\infty}f_{X\mid Y}(x\mid y)\,dx=1,\]
\[\boxed{P(a<X<b\mid Y=y)=\int_a^b f_{X\mid Y}(x\mid y)\,dx.}\]

此外，

\[\boxed{f(x,y)=f_{X\mid Y}(x\mid y)f_Y(y)}\]

以及

\[\boxed{f(x,y)=f_X(x)f_{Y\mid X}(y\mid x).}\]
4. PPT 例 3.4：甲乙接力完成工作

甲先工作 \(X\) 分钟，甲乙合计用时 \(Y\) 分钟。已知

\[X\sim U(0,30),\]

给定 \(X=x\) 时，\(Y\sim U(x,30)\)。

因此

\[f_X(x)= \begin{cases} 1/30,&0<x<30,\\ 0,&\text{其他}, \end{cases}\]
\[f_{Y\mid X}(y\mid x)= \begin{cases} \dfrac1{30-x},&x<y<30,\\ 0,&\text{其他}. \end{cases}\]

利用联合密度与条件密度的关系：

\[f(x,y)=f_X(x)f_{Y\mid X}(y\mid x),\]

得到

\[\boxed{ f(x,y)= \begin{cases} \dfrac1{30(30-x)},&0<x<y<30,\\ 0,&\text{其他}. \end{cases}}\]

先求 \(Y\) 的边际密度：

\[\begin{aligned} f_Y(y) &=\int_0^y\frac1{30(30-x)}\,dx\\ &=\frac1{30}\ln\frac{30}{30-y},\quad 0<y<30. \end{aligned}\]

于是

\[\boxed{ f_{X\mid Y}(x\mid y)= \begin{cases} \dfrac1{(30-x)\ln\frac{30}{30-y}},&0<x<y<30,\\ 0,&\text{其他}. \end{cases}}\]

若已知两人总共用了 25 分钟，求甲工作不超过 10 分钟的概率：

\[\begin{aligned} P(X\le10\mid Y=25) &=\int_0^{10}\frac1{(30-x)\ln6}\,dx\\ &=\frac{\ln30-\ln20}{\ln6}\\ &=\boxed{\frac{\ln(3/2)}{\ln6}\approx0.2263}. \end{aligned}\]

六、二元均匀分布

1. 定义

若 \((X,Y)\) 在有界平面区域 \(D\) 上服从均匀分布，则联合密度为

\[\boxed{ f(x,y)= \begin{cases} \dfrac1{S_D},&(x,y)\in D,\\ 0,&\text{其他}, \end{cases}}\]

其中 \(S_D\) 是区域 \(D\) 的面积。

2. 公式推导

假设区域 \(D\) 内密度为常数 \(c\)。由总概率为 1：

\[1=\iint_D c\,dx\,dy=cS_D.\]

所以

\[\boxed{c=\frac1{S_D}.}\]

若 \(D_1\subseteq D\)，则

\[\begin{aligned} P((X,Y)\in D_1) &=\iint_{D_1}\frac1{S_D}\,dx\,dy\\ &=\frac{S_{D_1}}{S_D}. \end{aligned}\]

因此

\[\boxed{\text{区域概率}=\frac{\text{目标区域面积}}{\text{总区域面积}}.}\]

该面积比方法只适用于区域内密度均匀的情况。

3. PPT 例 3.5：区域 \(\{|y|<x<1\}\) 上的均匀分布

设 \((X,Y)\) 在区域

\[D=\{(x,y):|y|<x<1\}\]

上服从均匀分布。这个区域可写成

\[0<x<1,\qquad -x<y<x.\]

区域面积为

\[S_D=\int_0^1 2x\,dx=1.\]

所以联合密度为

\[f(x,y)= \begin{cases} 1,&|y|<x<1,\\ 0,&\text{其他}. \end{cases}\]
（1）求 \(Y\) 的边际密度

先确定 \(Y\) 的取值范围：\(-1<y<1\)。固定 \(y\) 后，\(x\) 从 \(|y|\) 到 1，因此

\[f_Y(y)=\int_{|y|}^{1}1\,dx=1-|y|.\]

即

\[\boxed{ f_Y(y)= \begin{cases} 1-|y|,&-1<y<1,\\ 0,&\text{其他}. \end{cases}}\]
（2）求条件密度 \(f_{X\mid Y}(x\mid y)\)

当 \(-1<y<1\) 时，

\[f_{X\mid Y}(x\mid y) =\frac{f(x,y)}{f_Y(y)} =\frac1{1-|y|},\quad |y|<x<1.\]

所以

\[\boxed{ f_{X\mid Y}(x\mid y)= \begin{cases} \dfrac1{1-|y|},&|y|<x<1,\ -1<y<1,\\ 0,&\text{其他}. \end{cases}}\]

这说明给定 \(Y=y\) 后，\(X\) 在区间 \((|y|,1)\) 上服从均匀分布。

（3）求 \(P(X>2/3\mid Y=1/2)\)

当 \(Y=1/2\) 时，\(X\sim U(1/2,1)\)。因此可以直接使用均匀分布的区间长度比：

\[\begin{aligned} P(X>2/3\mid Y=1/2) &=\frac{1-2/3}{1-1/2}\\ &=\boxed{\frac23}. \end{aligned}\]

也可以用条件密度积分：

\[\int_{2/3}^{1} \frac1{1-1/2}\,dx =\int_{2/3}^{1}2\,dx=\frac23.\]
（4）从图形理解条件分布

固定 \(X=x\) 时，\(Y\) 的范围为 \((-x,x)\)，故

\[f_{Y\mid X}(y\mid x)=\frac1{2x},\quad -x<y<x.\]

所以 \(Y\mid X=x\sim U(-x,x)\)。这正是老师讲稿中“横切、竖切”理解二维均匀分布的例子：切片上的条件分布仍为均匀分布，但区间随固定的变量而变化。

七、二元正态分布

1. 联合密度与参数

若 \((X,Y)\) 的联合密度为

\[\boxed{ \begin{aligned} f(x,y) &=\frac{1}{2\pi\sigma_1\sigma_2\sqrt{1-\rho^2}}\\ &\quad\cdot\exp\left\{-\frac1{2(1-\rho^2)} \left[ \frac{(x-\mu_1)^2}{\sigma_1^2} -2\rho\frac{(x-\mu_1)(y-\mu_2)}{\sigma_1\sigma_2} +\frac{(y-\mu_2)^2}{\sigma_2^2} \right]\right\}, \end{aligned}}\]

其中

\[\mu_1,\mu_2\in\mathbb R,\quad \sigma_1>0,\ \sigma_2>0,\quad |\rho|<1,\]

则称 \((X,Y)\) 服从二元正态分布，记为

\[(X,Y)\sim N(\mu_1,\mu_2;\sigma_1^2,\sigma_2^2;\rho).\]

老师讲稿提示： 二元正态的联合密度公式较长，老师强调不必机械背诵整条公式；更重要的是理解五个参数的意义、记住边际仍为正态分布，以及条件分布也是正态分布。下面保留推导，是为了看懂结论从哪里来。

参数含义：

  • \(\mu_1,\mu_2\)：分别是 \(X,Y\) 的均值；
  • \(\sigma_1,\sigma_2\)：分别是 \(X,Y\) 的标准差；
  • \(\rho\)：相关系数，描述线性相关程度。

\(\rho>0\) 时分布倾向沿右上方向延伸；\(\rho<0\) 时倾向沿左上—右下方向延伸；\(\rho=0\) 时联合密度可以分解为两个边际正态密度的乘积。

2. 边际分布：从联合密度积分并配方

目标是求 \(f_X(x)\)：

\[f_X(x)=\int_{-\infty}^{+\infty}f(x,y)\,dy.\]

令

\[a=\frac{x-\mu_1}{\sigma_1},\qquad b=\frac{y-\mu_2}{\sigma_2}.\]

指数中的二次项为

\[a^2-2\rho ab+b^2.\]

配方：

\[\boxed{a^2-2\rho ab+b^2=(b-\rho a)^2+(1-\rho^2)a^2.}\]

所以指数可拆成

\[-\frac{a^2}{2}-\frac{(b-\rho a)^2}{2(1-\rho^2)}.\]

第一项不依赖 \(y\)，可以提出积分号。对第二项作变量替换

\[t=\frac{b-\rho a}{\sqrt{1-\rho^2}}, \qquad dy=\sigma_2\sqrt{1-\rho^2}\,dt.\]

使用标准高斯积分

\[\int_{-\infty}^{+\infty}e^{-t^2/2}\,dt=\sqrt{2\pi},\]

积分后得到

\[\boxed{ f_X(x)=\frac1{\sqrt{2\pi}\sigma_1} e^{-\frac{(x-\mu_1)^2}{2\sigma_1^2}}. }\]

因此

\[\boxed{X\sim N(\mu_1,\sigma_1^2).}\]

同理，

\[\boxed{Y\sim N(\mu_2,\sigma_2^2).}\]

两个边际分布都是一元正态分布，并且不依赖参数 \(\rho\)。

3. 条件分布：联合密度除以边际密度

根据条件密度公式，

\[f_{Y\mid X}(y\mid x)=\frac{f(x,y)}{f_X(x)}.\]

利用前面的配方，联合密度的指数部分可以写为

\[-\frac{(x-\mu_1)^2}{2\sigma_1^2} -\frac{ \left[y-\mu_2-\rho\frac{\sigma_2}{\sigma_1}(x-\mu_1)\right]^2 }{ 2(1-\rho^2)\sigma_2^2 }.\]

除以 \(f_X(x)\) 后，第一项以及相应的边际系数被约掉，得到

\[\boxed{ \begin{aligned} f_{Y\mid X}(y\mid x) &=\frac1{\sqrt{2\pi}\sigma_2\sqrt{1-\rho^2}}\\ &\quad\cdot\exp\left[ -\frac{\left(y-\mu_2-\rho\frac{\sigma_2}{\sigma_1}(x-\mu_1)\right)^2} {2(1-\rho^2)\sigma_2^2} \right]. \end{aligned}}\]

与一元正态密度比较可得

\[\boxed{ Y\mid X=x\sim N\left( \mu_2+\rho\frac{\sigma_2}{\sigma_1}(x-\mu_1), (1-\rho^2)\sigma_2^2 \right). }\]

同理，

\[\boxed{ X\mid Y=y\sim N\left( \mu_1+\rho\frac{\sigma_1}{\sigma_2}(y-\mu_2), (1-\rho^2)\sigma_1^2 \right). }\]
重点

条件均值会随已知变量变化；条件方差不依赖具体的 \(x\) 或 \(y\)。

3.4 随机变量的独立性

本节导读

PPT 顺序： 独立性定义 → 离散型判别 → 连续型判别 → 密度分解定理 → 二元正态独立性 → 多元推广。
PPT 主要对应第 72—92 页；教材对应第 101—105 页。
老师讲稿思路（约 01:49—02:18）： 独立的直观含义是“知道 \(X\) 的信息不会改变 \(Y\) 的分布”。离散型看联合分布律能否逐格拆成边际概率乘积；连续型看联合密度是否几乎处处等于边际密度乘积。判别时，定义域也是联合密度的一部分。

一、独立性的定义

若对任意实数集合 \(D_1,D_2\)，

\[\boxed{ P(X\in D_1,Y\in D_2) =P(X\in D_1)P(Y\in D_2), }\]

则称 \(X,Y\) 相互独立。

直观含义：知道 \(X\) 落在哪个集合中，不会改变 \(Y\) 落在任意指定集合中的概率，反之亦然。

二、联合分布函数的判别条件

公式

\[\boxed{ X,Y\text{ 独立} \iff F(x,y)=F_X(x)F_Y(y),\quad\forall x,y. }\]

推导

令 \(A=\{X\le x\}\)、\(B=\{Y\le y\}\)。若 \(X,Y\) 独立，则

\[P(A\cap B)=P(A)P(B).\]

换成分布函数记号：

\[F(x,y)=F_X(x)F_Y(y).\]

反过来，若该分解关系对所有 \(x,y\) 成立，则联合分布函数等于两个边际分布函数的乘积，两个随机变量独立。故它是充要条件。

三、离散型随机变量的独立性

联合分布律为 \(p_{ij}\)，边际概率为 \(p_{i\cdot}\)、\(p_{\cdot j}\)。独立的充要条件是

\[\boxed{p_{ij}=p_{i\cdot}p_{\cdot j}\quad\text{对所有 }i,j.}\]

推导

若独立，取事件 \(X=x_i\) 与 \(Y=y_j\)，便有

\[P(X=x_i,Y=y_j)=P(X=x_i)P(Y=y_j).\]

即 \(p_{ij}=p_{i\cdot}p_{\cdot j}\)。

反过来，若每个格子都满足该等式，对任意取值集合求和：

\[\begin{aligned} P(X\in I,Y\in J) &=\sum_{i\in I}\sum_{j\in J}p_{ij}\\ &=\sum_{i\in I}\sum_{j\in J}p_{i\cdot}p_{\cdot j}\\ &=\left(\sum_{i\in I}p_{i\cdot}\right) \left(\sum_{j\in J}p_{\cdot j}\right)\\ &=P(X\in I)P(Y\in J). \end{aligned}\]

因此独立性成立。

PPT 例 4.2：独立

联合分布表为：

\(X\backslash Y\) 0 1 \(P(X=i)\)
1 \(1/6\) \(2/6\) \(1/2\)
2 \(1/6\) \(2/6\) \(1/2\)
\(P(Y=j)\) \(1/3\) \(2/3\) 1

例如

\[P(X=1,Y=0)=\frac16 =\frac12\cdot\frac13=P(X=1)P(Y=0).\]

其余三个格子也都满足乘积关系，因此 \(X,Y\) 独立。

PPT 例 4.3：不独立

若

\[P(X=1,Y=0)=\frac16,\]

但

\[P(X=1)P(Y=0)=\frac12\cdot\frac12=\frac14,\]

则两者不相等，所以

\[\boxed{X,Y\text{ 不独立}.}\]
技巧

证明独立要检查所有格子；证明不独立只需找到一个反例。

PPT 例 4.4：利用独立性补全联合分布

若边际概率为

\[P(X=1)=0.25,\qquad P(X=2)=0.75,\]
\[P(Y=0)=0.04,\quad P(Y=1)=0.80,\quad P(Y=2)=0.16,\]

且 \(X,Y\) 独立，则每个联合概率由乘积直接得到。例如

\[P(X=1,Y=0)=0.25\times0.04=0.01,\]
\[P(X=2,Y=1)=0.75\times0.80=0.60.\]

1 0.01 0.20 0.04 0.25
2 0.03 0.60 0.12 0.75
\(P(Y=j)\) 0.04 0.80 0.16 1

四、连续型随机变量的独立性

1. 密度判别条件

\[\boxed{ X,Y\text{ 独立} \iff f(x,y)=f_X(x)f_Y(y)\quad\text{几乎处处}. }\]

“几乎处处”指允许等式在面积为零的集合上不成立；在一个正面积区域内不相等，则不能独立。

老师讲稿中的直观等价理解：条件分布不变

若离散型 \(X,Y\) 独立，且 \(P(X=x_i)>0\)，则

\[P(Y=y_j\mid X=x_i) =\frac{P(X=x_i,Y=y_j)}{P(X=x_i)} =\frac{P(X=x_i)P(Y=y_j)}{P(X=x_i)} =P(Y=y_j).\]

也就是说，给定不同的 \(X=x_i\)，\(Y\) 的条件分布律都等于同一个边际分布律。

连续型同理：

\[f_{Y\mid X}(y\mid x) =\frac{f(x,y)}{f_X(x)} =\frac{f_X(x)f_Y(y)}{f_X(x)} =f_Y(y).\]

所以独立性也可以理解为：已知 \(X\) 的取值，不会改变 \(Y\) 的分布；反过来也一样。

2. 推导思路

由联合分布函数的独立性条件：

\[F(x,y)=F_X(x)F_Y(y).\]

将三个分布函数写成密度积分：

\[\int_{-\infty}^{x}\int_{-\infty}^{y}f(u,v)\,dv\,du = \left(\int_{-\infty}^{x}f_X(u)\,du\right) \left(\int_{-\infty}^{y}f_Y(v)\,dv\right).\]

两个单重积分的乘积可写成二重积分：

\[\int_{-\infty}^{x}\int_{-\infty}^{y} f_X(u)f_Y(v)\,dv\,du.\]

所以对任意 \(x,y\)，两个密度在所有左下矩形上的积分相同；由密度与分布函数的关系，得到

\[f(x,y)=f_X(x)f_Y(y)\quad\text{几乎处处}.\]

反过来，对该密度分解式积分就会得到 \(F(x,y)=F_X(x)F_Y(y)\)，所以两变量独立。

老师讲稿补充：\(Y=X^2\) 时，为什么 \(X,Y\) 不独立？

设 \(X\sim U(-1,1)\)，并令 \(Y=X^2\)。直观上，\(Y\) 完全由 \(X\) 决定；一旦知道 \(X\)，\(Y\) 就确定了，所以它们不独立。

严格证明时，不要只拿 \(X=0\) 这样的单点举例，因为连续型 \(X\) 满足 \(P(X=0)=0\)。老师建议改用有正概率的区间：

令

\[A=\{0<X<0.1\},\qquad B=\{0.02<Y<0.03\}.\]

若 \(X\in A\)，则 \(0<Y=X^2<0.01\)，因此 \(A\) 与 \(B\) 不可能同时发生：

\[P(X\in A,Y\in B)=0.\]

但 \(P(X\in A)>0\)，且 \(P(Y\in B)>0\)，于是

\[P(X\in A,Y\in B)\ne P(X\in A)P(Y\in B).\]

这就找到了独立性定义的一个反例，所以 \(X,Y\) 不独立。

补充：\((X,X^2)\) 的概率全部落在抛物线 \(y=x^2\) 上；它既不是二维离散型随机变量，也不具有二维联合密度，是一个集中在曲线上的特殊分布。

五、密度分解定理

定理

连续型随机变量 \(X,Y\) 独立的充要条件是联合密度几乎处处可写为

\[\boxed{f(x,y)=m(x)n(y),}\]

其中 \(m\) 只依赖 \(x\)，\(n\) 只依赖 \(y\)，且联合密度满足归一化条件。

使用定理时最容易漏掉的一点：定义域也要能分开

判断 \(f(x,y)=m(x)n(y)\) 时，不能只看密度表达式的代数部分。分段定义里的“在哪些 \((x,y)\) 上非零”也是联合密度的一部分。

  • 若支持集是矩形 \(A\times B\)，常常可以写成“只与 \(x\) 有关的部分”乘以“只与 \(y\) 有关的部分”。
  • 若支持集是三角形，例如 \(0<x<y<2\)，固定 \(x\) 后 \(y\) 的范围是 \(x<y<2\)，会随 \(x\) 改变；这种支持条件通常无法拆成单独的 \(x\) 条件和 \(y\) 条件。

证明

必要性： 若 \(X,Y\) 独立，则

\[f(x,y)=f_X(x)f_Y(y).\]

令 \(m(x)=f_X(x)\)、\(n(y)=f_Y(y)\)，便有 \(f(x,y)=m(x)n(y)\)。

充分性： 假设 \(f(x,y)=m(x)n(y)\)。令

\[a=\int_{-\infty}^{+\infty}m(x)\,dx,\qquad b=\int_{-\infty}^{+\infty}n(y)\,dy.\]

由联合密度积分为 1：

\[1=\iint f(x,y)\,dx\,dy=ab.\]

边际密度为

\[f_X(x)=\int f(x,y)\,dy=bm(x),\]
\[f_Y(y)=\int f(x,y)\,dx=an(y).\]

所以

\[f_X(x)f_Y(y)=bm(x)\cdot an(y) =ab\,m(x)n(y)=f(x,y).\]

由连续型独立性判别条件，\(X,Y\) 独立。

PPT 例 4.1：指数型联合密度
\[f(x,y)= \begin{cases} 6e^{-(2x+3y)},&x>0,y>0,\\ 0,&\text{其他}. \end{cases}\]

求边际密度：

\[\begin{aligned} f_X(x)&=\int_0^\infty6e^{-(2x+3y)}\,dy =2e^{-2x},\\ f_Y(y)&=\int_0^\infty6e^{-(2x+3y)}\,dx =3e^{-3y}. \end{aligned}\]

因此

\[f_X(x)f_Y(y)=6e^{-(2x+3y)}=f(x,y),\]

所以 \(X,Y\) 独立。

PPT 第 77 页思考题：四种密度的判别

（1）

\[f(x,y)=e^{-2x},\quad x>0,\ 0<y<2.\]

可分解为 \(e^{-2x}\cdot1\)，且定义域是矩形，所以独立。其归一化也成立，因为

\[\int_0^\infty\int_0^2e^{-2x}\,dy\,dx=1.\]

（2）PPT 原页的公式是

\[f(x,y)= \begin{cases} xy/2,&0<x<y<2,\\ 0,&\text{其他}. \end{cases}\]

先检查归一化：

\[\int_0^2\int_0^y\frac{xy}{2}\,dx\,dy =\int_0^2\frac{y^3}{4}\,dy=1.\]

因此它是合法的联合密度。但 \(X,Y\) 不独立。虽然代数部分 \(xy/2=x\cdot(y/2)\) 看起来可以拆开，定义域 \(0<x<y<2\) 却是三角形，而不是 \(A\times B\) 形式的矩形支持集。

老师讲稿用条件取值范围解释这一点：若 \(X=1\)，则 \(1<Y<2\)；若 \(X=1.5\)，则 \(1.5<Y<2\)。已知 \(X\) 的取值会改变 \(Y\) 的允许范围，因此不能把它当作独立情形。判断密度能否分解时，必须连同定义域一起判断。

（3）

\[f(x,y)=x+y,\quad 0<x<1,\ 0<y<1.\]

边际密度为

\[f_X(x)=x+\frac12,\qquad f_Y(y)=y+\frac12.\]

其乘积

\[\left(x+\frac12\right)\left(y+\frac12\right)\]

一般不等于 \(x+y\)，所以不独立。

（4）

\[f(x,y)=xy,\quad 0<x<2,\ 0<y<1.\]

边际密度为

\[f_X(x)=\frac x2,\qquad f_Y(y)=2y.\]

因此 \(f_X(x)f_Y(y)=xy=f(x,y)\)，所以独立。

结论

PPT 给出的答案为（1）、（4）。同时要记住，判断独立性既要看表达式，也要看定义域。

六、二元正态分布的独立性

PPT 例 4.5：若 \((X,Y)\) 服从二元正态分布，则

\[\boxed{X,Y\text{ 独立}\iff\rho=0.}\]

证明：\(\rho=0\Rightarrow\) 独立

二元正态联合密度中，当 \(\rho=0\) 时，交叉项消失：

\[\begin{aligned} f(x,y) &=\frac1{2\pi\sigma_1\sigma_2} e^{-\frac{(x-\mu_1)^2}{2\sigma_1^2}} e^{-\frac{(y-\mu_2)^2}{2\sigma_2^2}}\\ &=f_X(x)f_Y(y). \end{aligned}\]

所以 \(X,Y\) 独立。

证明：独立 \(\Rightarrow\rho=0\)

若独立，则连续的密度满足

\[f(x,y)=f_X(x)f_Y(y).\]

在 \((\mu_1,\mu_2)\) 处，

\[f(\mu_1,\mu_2) =\frac1{2\pi\sigma_1\sigma_2\sqrt{1-\rho^2}},\]

而

\[f_X(\mu_1)f_Y(\mu_2) =\frac1{2\pi\sigma_1\sigma_2}.\]

令两者相等：

\[\frac1{\sqrt{1-\rho^2}}=1 \Rightarrow \rho^2=0 \Rightarrow\boxed{\rho=0}.\]
重要提醒

这是二元正态分布的特殊结论；一般随机变量相关系数为零并不必然独立。

七、PPT 例 4.6：独立指数分布变量的概率

\(X,Y\) 独立且同服从指数分布，密度为

\[f(x)=\frac12e^{-x/2},\quad x>0.\]

求 \(P(X\le2Y)\)。

由独立性，联合密度为

\[f(x,y)=\frac14e^{-(x+y)/2},\quad x>0,y>0.\]

区域 \(X\le2Y\) 等价于 \(y\ge x/2\)，所以

\[\begin{aligned} P(X\le2Y) &=\int_0^\infty\int_{x/2}^{\infty} \frac14e^{-(x+y)/2}\,dy\,dx\\ &=\int_0^\infty\frac12e^{-x/2}e^{-x/4}\,dx\\ &=\frac12\int_0^\infty e^{-3x/4}\,dx\\ &=\boxed{\frac23}. \end{aligned}\]

同分布不等于随机变量相等

老师讲稿还提醒：两个随机变量同分布，是指它们的分布函数相同；这不表示它们每次试验的取值都相等。

  • 若 \(X=Y\)（几乎处处），则它们同分布。
  • 反过来，同分布一般不能推出 \(X=Y\)。
  • 例如，把 10 次独立抛硬币的前 5 次正面次数记为 \(X\)，后 5 次正面次数记为 \(Y\)。两者都服从 \(B(5,1/2)\)，所以同分布；但前 5 次与后 5 次的正面次数不一定相同。

这也提醒我们：同分布、相等、独立是三个不同概念。

八、教材补充：3.4

1. 条件概率形式

若 \(X,Y\) 独立且 \(P(Y\in D_2)>0\)，则

\[\begin{aligned} P(X\in D_1\mid Y\in D_2) &=\frac{P(X\in D_1,Y\in D_2)}{P(Y\in D_2)}\\ &=\frac{P(X\in D_1)P(Y\in D_2)}{P(Y\in D_2)}\\ &=\boxed{P(X\in D_1)}. \end{aligned}\]

2. 多元独立性

\(X_1,\ldots,X_n\) 相互独立的分布函数判别条件为

\[\boxed{ F(x_1,\ldots,x_n)=\prod_{i=1}^nF_{X_i}(x_i). }\]

若连续型，则联合密度可分解为各边际密度的乘积；若离散型，则联合概率等于各边际概率的乘积。

3. 独立随机向量的性质

若随机向量 \((X_1,\ldots,X_m)\) 与 \((Y_1,\ldots,Y_n)\) 相互独立，则任意 \(X_i\) 与任意 \(Y_j\) 也独立。分别对两组变量施加相应的连续函数，所得两个函数随机变量仍独立。

一、基本思想：从 \((X,Y)\) 到 \(Z=g(X,Y)\)

已知二元随机变量 \((X,Y)\)，定义

\[Z=g(X,Y).\]

求 \(Z\) 的分布，实质上是把事件 \(\{Z=z\}\) 或 \(\{Z\le z\}\) 改写成关于原变量 \(X,Y\) 的事件，再利用已知的联合分布计算。

二、离散型随机变量函数的分布

1. 单个函数 \(Z=g(X,Y)\)

若

\[P(X=x_i,Y=y_j)=p_{ij},\]

则

\[\boxed{ P(Z=z)= \sum_{(i,j):\,g(x_i,y_j)=z}p_{ij}. }\]

推导

事件 \(\{Z=z\}\) 是所有满足 \(g(x_i,y_j)=z\) 的取值组合的并。不同的联合取值事件互斥，所以

\[P(Z=z)=\sum_{(i,j):g(x_i,y_j)=z}P(X=x_i,Y=y_j).\]

2. 两个函数 \((U,V)\)

若

\[U=u(X,Y),\qquad V=v(X,Y),\]

则

\[\boxed{ P(U=u,V=v)= \sum_{\substack{u(x_i,y_j)=u\\v(x_i,y_j)=v}}p_{ij}. }\]
做题步骤

列出原始取值 → 计算函数值 → 将映射到同一结果的概率相加 → 求边际分布。

先把函数事件翻译回 \(X\) 的取值范围，再用 \(X\) 的分布计算。

三、和 \(Z=X+Y\) 的分布：离散型情形

1. 一般公式

\[\boxed{ P(Z=z_k)=\sum_iP(X=x_i,Y=z_k-x_i). }\]

等价地，

\[\boxed{ P(Z=z_k)=\sum_jP(X=z_k-y_j,Y=y_j). }\]

推导

由 \(Z=X+Y\)，

\[\{Z=z_k\}=\{X+Y=z_k\}.\]

固定 \(X=x_i\) 后，必须有 \(Y=z_k-x_i\)，所以

\[\{Z=z_k\}=\bigcup_i\{X=x_i,Y=z_k-x_i\}.\]

这些事件互斥，对它们求和即可得到公式。

若 \(X,Y\) 独立，则进一步有

\[\boxed{ P(Z=z_k)=\sum_iP(X=x_i)P(Y=z_k-x_i). }\]
注意

只有独立时，才可把联合概率拆成边际概率的乘积。

2. PPT 例 5.3：独立泊松随机变量之和

设

\[X\sim P(\lambda_1),\qquad Y\sim P(\lambda_2),\]

且独立。令 \(Z=X+Y\)。

\[\begin{aligned} P(Z=k) &=\sum_{i=0}^{k}P(X=i)P(Y=k-i)\\ &=\sum_{i=0}^{k} e^{-\lambda_1}\frac{\lambda_1^i}{i!} e^{-\lambda_2}\frac{\lambda_2^{k-i}}{(k-i)!}\\ &=\frac{e^{-(\lambda_1+\lambda_2)}}{k!} \sum_{i=0}^{k}\binom ki\lambda_1^i\lambda_2^{k-i}. \end{aligned}\]

由二项式定理，

\[\sum_{i=0}^{k}\binom ki\lambda_1^i\lambda_2^{k-i} =(\lambda_1+\lambda_2)^k.\]

所以

\[P(Z=k)=e^{-(\lambda_1+\lambda_2)} \frac{(\lambda_1+\lambda_2)^k}{k!},\]

即

\[\boxed{X+Y\sim P(\lambda_1+\lambda_2).}\]

两个独立泊松随机变量的和仍服从泊松分布，参数相加。

四、连续型情形：卷积公式

1. 从分布函数出发

设 \((X,Y)\) 的联合密度为 \(f(x,y)\)，令 \(Z=X+Y\)。

\[\begin{aligned} F_Z(z) &=P(Z\le z)\\ &=P(X+Y\le z)\\ &=\iint_{x+y\le z}f(x,y)\,dx\,dy. \end{aligned}\]

改写积分次序：

\[F_Z(z)= \int_{-\infty}^{+\infty} \int_{-\infty}^{z-y}f(x,y)\,dx\,dy.\]

2. 对分布函数求导

根据变上限积分求导公式，

\[\frac{d}{dz}\int_{-\infty}^{z-y}f(x,y)\,dx=f(z-y,y).\]

所以

\[\boxed{ f_Z(z)=\int_{-\infty}^{+\infty}f(z-y,y)\,dy. }\]

令 \(x=z-y\)，可写成

\[\boxed{ f_Z(z)=\int_{-\infty}^{+\infty}f(x,z-x)\,dx. }\]

3. 独立时的卷积公式

若 \(X,Y\) 独立，则 \(f(x,y)=f_X(x)f_Y(y)\)。代入：

\[\begin{aligned} f_Z(z) &=\int_{-\infty}^{+\infty}f(x,z-x)\,dx\\ &=\int_{-\infty}^{+\infty}f_X(x)f_Y(z-x)\,dx. \end{aligned}\]

因此

\[\boxed{ f_Z(z)=\int_{-\infty}^{+\infty}f_X(x)f_Y(z-x)\,dx. }\]

这就是卷积公式；等价形式为

\[f_Z(z)=\int_{-\infty}^{+\infty}f_X(z-y)f_Y(y)\,dy.\]

实际计算时，只需在两个密度都非零的范围内积分。积分上下限必须由原始定义域决定。

老师讲稿对应的做题步骤

求 \(Z=X+Y\) 的密度时，固定一个 \(z\)，令 \(y=z-x\)。然后同时满足：

\[x\in \operatorname{supp}(X),\qquad z-x\in\operatorname{supp}(Y).\]

把这两个条件都改写成关于 \(x\) 的不等式，再取交集，就是积分范围。不要直接把积分上下限写成 \(-\infty,+\infty\) 后就不再检查：真正有效的积分区间来自两个变量的支持集相交。

4. PPT 例 5.4：两个独立标准正态变量之和

若 \(X,Y\overset{\text{独立}}{\sim}N(0,1)\)，\(Z=X+Y\)，则

\[f_Z(z)=\frac1{2\pi}\int_{-\infty}^{+\infty} e^{-\frac{x^2+(z-x)^2}{2}}\,dx.\]

配方：

\[x^2+(z-x)^2=2\left(x-\frac z2\right)^2+\frac{z^2}{2}.\]

于是

\[f_Z(z)=\frac{e^{-z^2/4}}{2\pi} \int_{-\infty}^{+\infty}e^{-(x-z/2)^2}\,dx.\]

利用

\[\int_{-\infty}^{+\infty}e^{-u^2}\,du=\sqrt\pi,\]

得到

\[f_Z(z)=\frac1{2\sqrt\pi}e^{-z^2/4}.\]

因此

\[\boxed{Z\sim N(0,2).}\]

一般地，若 \(X,Y\) 独立且分别服从 \(N(\mu_1,\sigma_1^2)\)、\(N(\mu_2,\sigma_2^2)\)，则

\[\boxed{ aX+bY+c\sim N(a\mu_1+b\mu_2+c,\ a^2\sigma_1^2+b^2\sigma_2^2). }\]
5. PPT 例 5.5：两个独立 \(U(0,1)\) 之和

设 \(X,Y\overset{\text{独立}}{\sim}U(0,1)\)，\(Z=X+Y\)。卷积积分的被积函数非零要求

\[0<x<1,\qquad0<z-x<1.\]

第二个条件等价于 \(z-1<x<z\)，所以有效区间是 \((0,1)\cap(z-1,z)\)。

  • 当 \(0<z\le1\)，区间为 \((0,z)\)，长度为 \(z\)；
  • 当 \(1<z<2\)，区间为 \((z-1,1)\)，长度为 \(2-z\)。

因此

\[\boxed{ f_Z(z)= \begin{cases} z,&0<z\le1,\\ 2-z,&1<z<2,\\ 0,&\text{其他}. \end{cases}}\]

密度呈三角形：和接近 0 或 2 时，可行组合较少；和在 1 附近时，可行组合较多。

6. PPT 例 5.6：三角形区域上的联合密度
\[f(x,y)= \begin{cases} 3x,&0<y<x<1,\\ 0,&\text{其他}. \end{cases}\]

令 \(Z=X+Y\)，则

\[f_Z(z)=\int_{-\infty}^{+\infty}f(x,z-x)\,dx.\]

非零条件为

\[0<z-x<x<1.\]

分别整理：

\[x<z,\qquad x>\frac z2,\qquad x<1.\]

所以

\[\frac z2<x<\min(z,1),\quad 0<z<2.\]

当 \(0<z\le1\)：

\[\begin{aligned} f_Z(z)&=\int_{z/2}^{z}3x\,dx\\ &=\frac98z^2. \end{aligned}\]

当 \(1<z<2\)：

\[\begin{aligned} f_Z(z)&=\int_{z/2}^{1}3x\,dx\\ &=\frac38(4-z^2). \end{aligned}\]

所以

\[\boxed{ f_Z(z)= \begin{cases} \dfrac98z^2,&0<z\le1,\\[3pt] \dfrac38(4-z^2),&1<z<2,\\ 0,&\text{其他}. \end{cases}}\]

本题重点不是积分技巧，而是把 \(y\) 替换成 \(z-x\) 后，重新解不等式确定上下限。

五、一个离散型、一个连续型：全概率公式

PPT 例 5.7：\(X\) 取 100、150、200 三个值，各自概率 \(1/3\)；\(Y\sim N(150,400)\)，且 \(X,Y\) 独立。令 \(Z=X+Y\)。

先按 \(X\) 的取值分类：

\[\begin{aligned} F_Z(t) &=P(X+Y\le t)\\ &=\frac13\left[ F_Y(t-100)+F_Y(t-150)+F_Y(t-200) \right]. \end{aligned}\]

对 \(t\) 求导：

\[\boxed{ f_Z(t)=\frac13\left[ f_Y(t-100)+f_Y(t-150)+f_Y(t-200) \right]. }\]

此处 \(Y\sim N(150,400)\)，标准差为 20。于是

\[\begin{aligned} P(Z>300) &=\frac13\left[ P(Y>200)+P(Y>150)+P(Y>100) \right]\\ &=\frac13\left[ 1-\Phi(2.5)+\frac12+\Phi(2.5) \right]\\ &=\boxed{\frac12}. \end{aligned}\]
方法

一个变量离散、另一个连续时，按离散变量的可能取值分类，利用全概率公式。

六、最大值与最小值的分布

设 \(X,Y\) 独立，分布函数分别为 \(F_X,F_Y\)，定义

\[M=\max(X,Y),\qquad N=\min(X,Y).\]

1. 最大值

\[\{M\le z\}=\{X\le z,Y\le z\}.\]

所以

\[\begin{aligned} F_M(z)&=P(M\le z)\\ &=P(X\le z,Y\le z)\\ &=P(X\le z)P(Y\le z). \end{aligned}\]

因此

\[\boxed{F_M(z)=F_X(z)F_Y(z).}\]

2. 最小值

利用补事件：

\[\begin{aligned} F_N(z)&=P(N\le z)\\ &=1-P(N>z)\\ &=1-P(X>z,Y>z). \end{aligned}\]

由独立性，

\[P(X>z,Y>z)=[1-F_X(z)][1-F_Y(z)].\]

因此

\[\boxed{F_N(z)=1-[1-F_X(z)][1-F_Y(z)].}\]

3. 对应密度

若分布函数可导，则

\[\boxed{f_M(z)=f_X(z)F_Y(z)+F_X(z)f_Y(z),}\]
\[\boxed{f_N(z)=f_X(z)[1-F_Y(z)]+f_Y(z)[1-F_X(z)].}\]
4. PPT 例 5.8：两个独立 \(U(0,1)\) 的最大值与最小值

当 \(0\le z\le1\) 时，\(F_X(z)=F_Y(z)=z\)。

最大值：

\[F_M(z)=z^2 \quad\Longrightarrow\quad \boxed{f_M(z)=2z,\ 0<z<1.}\]

最小值：

\[F_N(z)=1-(1-z)^2 \quad\Longrightarrow\quad \boxed{f_N(z)=2(1-z),\ 0<z<1.}\]

5. 推广到 \(n\) 个独立随机变量

若 \(X_1,\ldots,X_n\) 相互独立，分布函数分别为 \(F_i\)，则

\[\boxed{ F_{\max_i X_i}(z)=\prod_{i=1}^{n}F_i(z), }\]
\[\boxed{ F_{\min_i X_i}(z)=1-\prod_{i=1}^{n}[1-F_i(z)]. }\]

若它们同分布，公共分布函数为 \(F\)，则分别简化为 \(F(z)^n\) 与 \(1-[1-F(z)]^n\)。

6. PPT 例 5.9：系统寿命

两个独立子系统的寿命分别为

\[X\sim E(\alpha),\qquad Y\sim E(\beta),\qquad \alpha\ne\beta.\]

指数分布的生存函数为

\[P(X>z)=e^{-\alpha z},\quad z>0.\]
（1）串联：\(Z=\min(X,Y)\)

任何一个子系统损坏，整个系统停止工作。

\[P(Z>z)=P(X>z)P(Y>z)=e^{-(\alpha+\beta)z}.\]

所以

\[F_Z(z)=1-e^{-(\alpha+\beta)z},\]

求导得

\[\boxed{f_Z(z)=(\alpha+\beta)e^{-(\alpha+\beta)z},\quad z>0.}\]

即 \(Z\sim E(\alpha+\beta)\)。

（2）并联：\(Z=\max(X,Y)\)

只有两个子系统都损坏，系统才停止工作。

\[F_Z(z)=F_X(z)F_Y(z) =(1-e^{-\alpha z})(1-e^{-\beta z}).\]

求导得

\[\boxed{ f_Z(z)=\alpha e^{-\alpha z}+\beta e^{-\beta z} -(\alpha+\beta)e^{-(\alpha+\beta)z},\quad z>0. }\]
（3）备用：\(Z=X+Y\)

第一个子系统损坏后，第二个才开始工作，总寿命为两者之和。

\[\begin{aligned} f_Z(z) &=\int_0^z\alpha e^{-\alpha(z-y)}\beta e^{-\beta y}\,dy\\ &=\boxed{ \frac{\alpha\beta}{\beta-\alpha} (e^{-\alpha z}-e^{-\beta z}) },\quad z>0. \end{aligned}\]

三种结构分别对应最小值、最大值、和。先写清楚系统寿命与 \(X,Y\) 的关系，再选择公式。

七、PPT 例 5.10：带噪声的信号判断

发送信号 \(X\) 取 \(1\) 或 \(-1\)：

\[P(X=1)=p,\qquad P(X=-1)=1-p.\]

噪声 \(N\sim N(0,\sigma^2)\)，且与 \(X\) 独立；接收信号为

\[Y=X+N.\]

判断规则：\(Y\ge0\) 时判为 \(X=1\)，否则判为 \(X=-1\)。

若 \(X=1\)，则

\[\begin{aligned} P(Y\ge0\mid X=1) &=P(N\ge-1)\\ &=1-\Phi(-1/\sigma)\\ &=\boxed{\Phi(1/\sigma)}. \end{aligned}\]

若已知 \(Y\ge0\)，根据贝叶斯公式：

\[\boxed{ P(X=1\mid Y\ge0)= \frac{p\Phi(1/\sigma)} {p\Phi(1/\sigma)+(1-p)[1-\Phi(1/\sigma)]}. }\]

同理，

\[\boxed{ P(X=-1\mid Y<0)= \frac{(1-p)\Phi(1/\sigma)} {(1-p)\Phi(1/\sigma)+p[1-\Phi(1/\sigma)]}. }\]

当 \(p=1/2\) 时，两种方向的条件判断正确率相同，均为 \(\Phi(1/\sigma)\)。噪声标准差越小，信号被误判的概率通常越小。

八、PPT 例 5.11：随机选择 \(X\) 或 \(Y\)

设

\[Z=AX+(1-A)Y,\]

其中 \(A\sim B(1,p)\)，且 \(A,X,Y\) 相互独立。

  • \(A=1\) 时 \(Z=X\)；
  • \(A=0\) 时 \(Z=Y\)。

利用全概率公式：

\[\begin{aligned} F_Z(z) &=P(Z\le z)\\ &=P(A=1)P(X\le z)+P(A=0)P(Y\le z). \end{aligned}\]

因此

\[\boxed{F_Z(z)=pF_X(z)+(1-p)F_Y(z).}\]

若 \(p=1/2\)、\(X\equiv2\)、\(Y\sim U(0,1)\)，则

\[F_Z(z)= \begin{cases} 0,&z<0,\\ z/2,&0\le z<1,\\ 1/2,&1\le z<2,\\ 1,&z\ge2. \end{cases}\]

在 \(z=2\) 处分布函数跳跃 \(1/2\)，即 \(P(Z=2)=1/2\)；同时 \(0<z<1\) 上有连续部分。因此 \(Z\) 是混合型随机变量，既非纯离散型，也非纯连续型。

九、教材补充：3.5

1. 等待时间与服务时间之和

教材例 3.5.3：等待时间 \(X\sim E(\lambda)\)，服务时间 \(Y\sim U(0,20)\)，二者独立。令 \(Z=X+Y\)。

\[f_X(x)=\lambda e^{-\lambda x},\quad x>0, \qquad f_Y(y)=\frac1{20},\quad0<y<20.\]

由卷积公式

\[f_Z(t)=\int_{-\infty}^{+\infty}f_X(x)f_Y(t-x)\,dx.\]

非零条件为 \(x>0\) 且 \(0<t-x<20\)，即 \(t-20<x<t\)。因此：

  • \(t\le0\)：没有有效区间，\(f_Z(t)=0\)；
  • \(0<t<20\)：有效区间为 \(0<x<t\)；
  • \(t\ge20\)：有效区间为 \(t-20<x<t\)。

所以

\[\boxed{ f_Z(t)= \begin{cases} 0,&t\le0,\\[2pt] \dfrac{1-e^{-\lambda t}}{20},&0<t<20,\\[6pt] \dfrac{e^{-\lambda(t-20)}-e^{-\lambda t}}{20},&t\ge20. \end{cases}}\]

当 \(\lambda=1/20\) 时，

\[P(Z\le45)=1-e^{-45/20}(e-1)\approx\boxed{0.8189}.\]

教材这题的重点是：卷积公式一样，但支持集的交集决定了分段积分范围。

2. 正态变量之和的推广

若 \(X_1,\ldots,X_n\) 相互独立，且 \(X_i\sim N(\mu_i,\sigma_i^2)\)，则

\[\boxed{ \sum_{i=1}^nX_i\sim N\left(\sum_{i=1}^n\mu_i,\sum_{i=1}^n\sigma_i^2\right). }\]

独立正态随机变量的线性组合仍服从正态分布。

3. 教材版本的酬金例题

教材例 3.5.5 与 PPT 例 5.7 思路相同，但参数不同：教材版本取 \(Y\sim N(150,36)\)，标准差为 6；PPT 版本取 \(Y\sim N(150,400)\)，标准差为 20。两者不要混为一题。

如果 \(X\) 取 \(100,150,200\)，各自概率 \(1/3\)，且与正态变量 \(Y\) 独立，则通用结论为

\[F_Z(t)=\frac13\left[F_Y(t-100)+F_Y(t-150)+F_Y(t-200)\right],\]
\[f_Z(t)=\frac13\left[f_Y(t-100)+f_Y(t-150)+f_Y(t-200)\right].\]
4. 四个独立指数寿命的最大值、最小值

教材例 3.5.6：\(X_1,\ldots,X_4\) 独立且服从 \(E(\lambda)\)。令

\[N=\min(X_1,X_2,X_3,X_4),\qquad M=\max(X_1,X_2,X_3,X_4).\]

当 \(t>0\) 时，

\[F_N(t)=1-P(X_1>t,\ldots,X_4>t) =1-e^{-4\lambda t}.\]

所以

\[\boxed{f_N(t)=4\lambda e^{-4\lambda t},\quad t>0.}\]

最大值的分布函数为

\[F_M(t)=\prod_{i=1}^4F_{X_i}(t) =(1-e^{-\lambda t})^4.\]

求导：

\[\boxed{ f_M(t)=4\lambda e^{-\lambda t}(1-e^{-\lambda t})^3,\quad t>0. }\]

教材还给出混合结构的系统寿命

\[T=\min\{\max(X_1,X_2),X_3,X_4\}.\]

当 \(t>0\) 时，

\[\begin{aligned} P(T>t) &=P(\max(X_1,X_2)>t)P(X_3>t)P(X_4>t)\\ &=[1-(1-e^{-\lambda t})^2]e^{-2\lambda t}\\ &=\boxed{e^{-3\lambda t}(2-e^{-\lambda t})}. \end{aligned}\]

考前易错点总整理

  1. 边际分布不是联合分布。 联合分布可以求出边际分布；只知道边际分布，通常无法唯一恢复联合分布。
  2. 条件概率分母别放错。 \(P(X=x\mid Y=y)\) 的分母是 \(P(Y=y)\)；\(f_{X\mid Y}(x\mid y)\) 的分母是 \(f_Y(y)\)。
  3. 密度不是概率。 \(f(x,y)\) 不是 \(P(X=x,Y=y)\)；二维连续型变量落在一条直线上的概率为 0。
  4. 积分范围由定义域决定。 求 \(f_X(x)\) 时固定 \(x\)，求 \(f_Y(y)\) 时固定 \(y\)；遇到弯曲区域要先画图或解不等式。
  5. 独立性分解要包含支持集。 不能只把 \(xy/2\) 这种代数部分拆成 \(x\cdot y/2\)，还要检查 \(0<x<y<2\) 这样的区域条件能否拆开。
  6. 证明不独立只需要一个反例。 离散型找一个格子不满足乘积关系；一般定义下也可以找两个集合，使联合概率不等于边际概率乘积。
  7. 零相关不等于独立。 只有二元正态分布中，才有独立当且仅当 \(\rho=0\) 的结论。
  8. 卷积先找支持集交集。 先写 \(x\) 的取值条件与 \(z-x\) 的取值条件，再确定分段积分范围。
  9. 最大值和最小值从事件出发。 \(\max(X,Y)\le z\) 等价于 \(X\le z,Y\le z\)；\(\min(X,Y)>z\) 等价于 \(X>z,Y>z\)。
  10. 同分布不等于相等。 同分布只说明分布函数相同，不说明每次试验的取值相同。

第三章公式速查

展开公式速查

3.1 离散型

联合分布律：

\[p_{ij}=P(X=x_i,Y=y_j),\quad p_{ij}\ge0,\quad\sum_i\sum_jp_{ij}=1.\]

边际分布律：

\[P(X=x_i)=\sum_jp_{ij},\qquad P(Y=y_j)=\sum_ip_{ij}.\]

条件分布律：

\[P(X=x_i\mid Y=y_j)=\frac{p_{ij}}{p_{\cdot j}},\]
\[P(Y=y_j\mid X=x_i)=\frac{p_{ij}}{p_{i\cdot}}.\]

3.2 分布函数

\[F(x,y)=P(X\le x,Y\le y).\]
\[F_X(x)=F(x,+\infty),\qquad F_Y(y)=F(+\infty,y).\]

矩形概率：

\[\begin{aligned} &P(x_1<X\le x_2,\ y_1<Y\le y_2)\\ &=F(x_2,y_2)-F(x_1,y_2)-F(x_2,y_1)+F(x_1,y_1). \end{aligned}\]

3.3 连续型

联合密度归一化：

\[\iint_{\mathbb R^2}f(x,y)\,dx\,dy=1.\]

区域概率：

\[P((X,Y)\in G)=\iint_Gf(x,y)\,dx\,dy.\]

边际密度：

\[f_X(x)=\int_{-\infty}^{+\infty}f(x,y)\,dy,\qquad f_Y(y)=\int_{-\infty}^{+\infty}f(x,y)\,dx.\]

条件密度：

\[f_{X\mid Y}(x\mid y)=\frac{f(x,y)}{f_Y(y)},\qquad f_{Y\mid X}(y\mid x)=\frac{f(x,y)}{f_X(x)}.\]

二元均匀分布：

\[f(x,y)=\frac1{S_D}\quad((x,y)\in D).\]

二元正态条件分布：

\[Y\mid X=x\sim N\left(\mu_2+\rho\frac{\sigma_2}{\sigma_1}(x-\mu_1), (1-\rho^2)\sigma_2^2\right).\]

3.4 独立性

一般定义：

\[P(X\in D_1,Y\in D_2)=P(X\in D_1)P(Y\in D_2).\]

分布函数判别：

\[F(x,y)=F_X(x)F_Y(y).\]

离散型判别：

\[p_{ij}=p_{i\cdot}p_{\cdot j}.\]

连续型判别：

\[f(x,y)=f_X(x)f_Y(y)\quad\text{几乎处处}.\]

二元正态特殊结论：

\[X,Y\text{ 独立}\iff\rho=0.\]

3.5 函数分布

离散型函数：

\[P(Z=z)=\sum_{(i,j):g(x_i,y_j)=z}p_{ij}.\]

离散型和：

\[P(X+Y=z_k)=\sum_iP(X=x_i,Y=z_k-x_i).\]

独立连续型和（卷积）：

\[f_{X+Y}(z)=\int_{-\infty}^{+\infty}f_X(x)f_Y(z-x)\,dx.\]

最大值：

\[F_{\max(X,Y)}(z)=F_X(z)F_Y(z)\quad(X,Y\text{ 独立}).\]

最小值：

\[F_{\min(X,Y)}(z)=1-[1-F_X(z)][1-F_Y(z)] \quad(X,Y\text{ 独立}).\]

随机选择变量：

\[F_{AX+(1-A)Y}(z)=pF_X(z)+(1-p)F_Y(z), \quad A\sim B(1,p),\ A\perp(X,Y).\]

自检答案要点

  1. 对联合分布律按另一个变量求和。
  2. 条件概率分母是条件事件的概率。
  3. 条件事件不同，分母不同。
  4. \(F(x,y)=P(X\le x,Y\le y)\)。
  5. \(F_X(x)=F(x,+\infty)\)，\(F_Y(y)=F(+\infty,y)\)。
  6. 用四个联合分布函数值作增量差。
  7. 连续型点事件概率通常为 0。
  8. \(f\ge0\)、全平面二重积分为 1；区域概率是密度在区域上的积分。
  9. 求 \(f_X\) 对 \(y\) 积分；求 \(f_Y\) 对 \(x\) 积分。
  10. 分母是已知条件变量的边际密度。
  11. 因区域内密度恒为总区域面积的倒数。
  12. 边际仍是一元正态；条件均值与条件方差见 3.3 节公式。
  13. \(p_{ij}=p_{i\cdot}p_{\cdot j}\) 对所有 \(i,j\) 成立。
  14. \(f(x,y)=f_X(x)f_Y(y)\) 几乎处处。
  15. 一个联合概率或密度值不符合乘积关系，就足以否定独立。
  16. 二元正态时独立当且仅当 \(\rho=0\)；一般情形不成立。
  17. 找出所有映射到同一 \(z\) 的原始取值组合，并将概率相加。
  18. 由原始变量的支持集与 \(y=z-x\) 确定。
  19. 因为有效积分区间长度随 \(z\) 先增后减。
  20. 从事件 \(\{\max\le z\}\) 与补事件 \(\{\min>z\}\) 出发。
  21. 一个分量可能带来离散点概率，另一个分量可能带来连续部分。
  22. 定义域是三角形 \(0<x<y<2\)，给定 \(X=x\) 后，\(Y\) 的允许范围会随 \(x\) 改变，联合密度的完整定义不能拆成只依赖 \(x\) 与只依赖 \(y\) 的两个部分。
  23. 独立时，\(P(Y=y\mid X=x)=P(Y=y)\)（离散型）；连续型对应 \(f_{Y\mid X}(y\mid x)=f_Y(y)\)。
  24. 直线 \(y=2x+4\) 在平面上的面积为零，二维连续型分布对零面积集合赋予的概率为零。
