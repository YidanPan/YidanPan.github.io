1.写一个操作系统前置物料

1. 某种 Linux 系统 —— 我自己运行的是 Ubuntu 18.04，而且很多其他的 CTF 题目也是以它为目标的。不过市面上有非常多的 Linux 版本…… 在你真正搞懂这个“类 Unix 的玩意儿”到底怎么运作之前，你可能得把你搭好的系统重装个上百万次，所以别太焦虑，随便挑一个装上就行。 ; * 你可能想用虚拟机（Virtual Machine）来搞这个，完全没问题。 ; * 如果你真的很极客，甚至可以用容器（Container/Docker）来封装它。那会很酷…… 但没那个必要。 ; * 如果你用的是 Windows，Windows 的 Linux 子系统（WSL）真的非常香…… 我超级喜欢它。

2. NASM —— 负责把我们下面写的文本转换成计算机真正能读懂的东西。 （汇编编译器）

  • 额，好吧，坏消息是计算机其实太聪明，读不懂人类的文本。好消息是，把文本变得让机器可读非常简单：下面写的每一行代码，都会被翻译成 1 到 15 个字节（Bytes）。这些字节计算机能完美理解——但在我们眼里，它们只是一堆随机数字的集合。
    （在 Ubuntu 上，只需要简单运行：sudo apt install nasm）
    相当于是能够把汇编语言转换成机器语言

3. QEMU —— 用来运行我们自己写的这个操作系统的模拟器。

  • （在 Ubuntu 上，只需要简单运行：sudo apt install qemu）

4. 应该还需要一个文本编辑器，用来编辑像这个挑战里一样的文本。我个人喜欢 Visual Studio Code…… 它有一些很棒的汇编（asm）扩展插件。

5. 一个终端（T3rMiNaL）！ 这东西超好用。你在里面敲字，就能让各种事情发生…… 这基本是不言自明的，我们将通过终端与这次挑战（以及未来许多其他挑战）中用到的工具进行交互。 ; * 不过别害怕，沿途你也会用到很多精美的图形化工具。

6. 要想在逆向工程（Reverse Engineering）中真正有所建树，你还需要一个反汇编器（Disassembler）。 ; * 反汇编器能把那一堆看起来像乱码的随机数字，重新翻译成人类能看懂的东西。 ; * 那些优秀的反汇编器还能对程序进行一些额外的分析，让反汇编的结果更准确，比如 Binary Ninja！！<- 有史以来最赞的工具。:) 而且声明一下，我可没有签什么代言合同被迫说这话。我也没有被关在盒子里。我也没有想念天上那个巨大的死亡激光。那个死亡激光对我可凶了。

2.x86汇编语言

2.1x86 汇编语言简介：

值得一提的是，世界上有许多种不同的汇编语言；因为有很多种不同设计目标和应用场景的计算机，而“处理器（CPU）”是所有这些设备的大脑。所以，为了控制这些不同的处理器，人们发展出了好几种不同的汇编语言。手机会使用专门针对低功耗设计的处理器，比如 ARM 处理器；而台式机则会使用更强大、更快速、功能更多的处理器，比如英特尔（Intel）和 AMD 自家的 x86 处理器！ ; 这也是我们将要学习的，因为你在“真实自然环境”中要去漏洞利用（Exploit）的大多数服务，都会运行在重型 x86 计算机上——顺带提一句，正因为它的设计极其强悍，所以它要复杂得多，以至于在实现处理器的指令时偶尔会出现一些小故障，我们称之为漏洞（Vulnerabilities），利用这些漏洞我们可以做出设计之外的事情——比如泄露数据。

_start: ; 这是一个“标签（Label）”…… 它本身并不是一条机器指令。它只是写给我们人类看的标记。我们把它放在这里是为了以后方便引用。这样一来，如果我们后面在代码里提到了 _start，NASM 编译器就会知道我们指的是这个标签紧跟在后面的那个元素。

cli ; 这条指令你平时在写普通程序时基本见不到…… 所以不用太担心。它的作用大概就是：就算你此时往电脑上插个 USB 闪存盘，也不会把处理器吓跑而打断我们的核心工作。

2.2 基础知识

  • 计算机三大语言：高级语言（java、c等）；汇编语言（mov ax，0）；机器语言（二进制）
  • CPU 可以执行机器指令，进行运算
  • 寄存器：CPU 中可以存储数据的器件(可以暂且理解为变量)
  • 汇编语言组成：
    • 汇编指令：有对应的机器码，是机器码的助记符
    • 伪指令：由编译器执行，没有对应机器码
    • 其他符号（+-*/ 等）：由编译器识别，没有对应机器码
  • CPU 从内存读取数据的过程：
    • CPU 通过地址线将地址信息发出
    • CPU 通过控制线发出内存读命令，告知指定存储器芯片要从中读取数据
    • 存储器将所需地址处的数据通过数据线送给 CPU
  • 存储器芯片从读写上分为 随机存储器（RAM）和 只读存储器（ROM）
    • RAM 可读可写，但必须带电存储，关机后内容丢失
    • ROM 只读不写，但关机后内容不丢失
