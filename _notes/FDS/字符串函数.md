用字符串函数的标准库是include<string.h>
# 1.基础操作：长度与复制

## `strlen(s)` —— 获取字符串长度

- **作用：** 计算字符串的字符个数，**不包括**末尾的 `\0`。
    
- **用法：** `size_t len = strlen(str);`
    
- **例子：**
> [!note] C
> ```c
> char s[] = "Hello";
> printf("%zu", strlen(s)); // 输出 5
> ```
>     
    

## `strcpy(dest, src)` —— 字符串拷贝

- **作用：** 将 `src` 完整拷贝到 `dest` 中（包括 `\0`）。
    
- **注意：** `dest` 空间必须足够大，否则会溢出。
    
- **例子：**
    
    C
> [!note] e.g.
> ```c
>     char src[] = "Copy Me";
>     char dest[20];
>     strcpy(dest, src); 
> ```
    

## `* strncpy(dest, src, n)` —— 安全拷贝

- **作用：** 最多拷贝 `n` 个字符。比 `strcpy` 更安全，防止溢出。

# 2. 拼接与比较

## `strcat(dest, src)` —— 字符串拼接

- **作用：** 把 `src` 接到 `dest` 的末尾。
    
- **用法：** `dest` 必须有足够的剩余空间。
    
- **例子：**
    C
>[!note] e.g. 
>```c
>     char s1[20] = "High ";
>     char s2[] = "Five";
>     strcat(s1, s2); // s1 变为 "High Five"
>```
    

## `strcmp(s1, s2)` —— 字符串比较

- **作用：** 按照 ASCII 码逐个字符比较。
    
- **返回值：** 
	- == `0`：相等
    - ` > 0`：s1 大于 s2
        
    - ` < 0`：s1 小于 s2
        
- **注意：** 不能直接用 `if(s1 == s2)`，那是在比较地址！
    
- **例子：**
    
    C
>[!note] e.g.
>```c
>     if (strcmp(op, "Push") == 0) { /* 匹配成功 */ }
>```

# 3. 查找与分割

## `strchr(s, c)` —— 查找字符

- **作用：** 在字符串中查找字符 `c` 第一次出现的位置。
    
- **返回：** 返回指向该字符的指针，找不到则返回 `NULL`。
    

## `strstr(haystack, needle)` —— 查找子串

- **作用：** 在一个长字符串中查找是否包含另一个短字符串。
    
- **例子：**
    
    C
>[!note] e.g.
>```c
>     char *p = strstr("Hello World", "World");
>     if(p) printf("找到了！位置在 %ld", p - str);
>```
    

## `strtok(s, delim)` —— 字符串分割

- **作用：** 根据分隔符（如空格、逗号）切分字符串。
    
- **注意：** 它是“有损”的，会修改原字符串（把分隔符换成 `\0`）。

# 4. 进阶：格式化处理（在 `<stdio.h>` 中）

虽然不在 `string.h` 里，但这两个函数在处理字符串逻辑时极度常用：

|**函数**|**作用**|**例子**|
|---|---|---|
|**`sprintf`**|把各种类型“打印”到字符串里（拼接神器）|`sprintf(buf, "%d-%d", year, month);`|
|**`sscanf`**|从字符串里“提取”变量（解析神器）|`sscanf("Push 10", "%s %d", op, &val);`|

# 综合对比表

| **函数名**  | **核心功能** | **是否修改原串** | **安全风险** |
| -------- | -------- | ---------- | -------- |
| `strlen` | 算长度      | 否          | 无        |
| `strcpy` | 覆盖拷贝     | 是          | 高（易溢出）   |
| `strcat` | 尾部追加     | 是          | 高        |
| `strcmp` | 比大小      | 否          | 低        |
| `strtok` | 暴力切分     | **是**      | 中        |
### 💡 一个避坑小贴士

在做你图中的那道题时，如果要清空字符串变量，最快的方法是： `str[0] = '\0';` 这在逻辑上就相当于把字符串清空了，因为所有字符串函数遇到第一个 `\0` 就会停止。
