# Lua
`.lua` 文件就是 **Lua 脚本语言的源代码文件**。它本质上是普通文本，记录的是 Lua 代码，可以直接用文本编辑器查看和修改。Lua 因为体积小、速度快、易于嵌入，广泛用于游戏开发、软件扩展、自动化脚本以及 CTF 和逆向工程中。如果你在逆向一个程序时看到很多 `.lua` 文件，通常意味着程序把业务逻辑或脚本放在 Lua 中，而不是全部编译进 C/C++ 可执行文件里。

# Base64编码
base64只是一种编码规则，不是加密手段。它是负责把任意二进制字符串转化为可打印的64个字符。大小写的26个字母加上是个数字加上+ /，共64个。还有一个特殊字符=，它是当做补位符号，用来对齐的符号。
它是每6bit处理，但是一般转化为ASCII码是为8位，这种转化后如果不是6的倍数，就在后面补0凑成6的倍数，多余用=补位。

# 计算机网络问题
### 盲注
既然服务器永远是个扑克脸（既不报错，也不改变提示文字），黑客发出的恶意探测代码就像石沉大海，完全得不到任何**视觉上**的反馈。

在这个系统面前，黑客仿佛是个“盲人”，完全看不到数据库内部执行的结果，这就叫“盲注（Blind Injection）”。

### 时间盲注
在这个局限下，攻击者利用了数据库自带的休眠函数 `SLEEP(0.8)`，对数据库下达了一个带有条件判断（布尔值 True / False）的指令。把 Payload 翻译成大白话，就是黑客在对数据库说：
> “数据库，如果你藏着的那个 Flag 的第一个字母 ASCII 码大于 79，你就给我去睡 0.8 秒钟，醒了再把网页发给我；如果不大于 79，你就立刻把网页发给我。”
这时候，**“时间”就成了 True 和 False 的唯一载体：**
- **情况 A（假 / False）：** 如果字母 ASCII 码不大于 79，数据库立刻执行完毕。黑客看到网页瞬间（例如 0.05 秒）就加载出来了。虽然页面上还是那句熟悉的 `Invalid credentials`，但黑客通过时间立刻明白：**刚才猜错了。**
- **情况 B（真 / True）：** 如果字母 ASCII 码真的大于 79，数据库就会乖乖去睡 0.8 秒。黑客发包后掐着秒表，发现等了将近 1 秒钟网页才弹出来。虽然页面上依旧写着 `Invalid credentials`，但黑客心里清楚：**刚才猜对了。**

# SQL
SQL（Structured Query Language，结构化查询语言）是专门用于与关系型数据库进行“沟通”的标准编程语言。
SQL 的应用几乎涵盖了所有涉及数据存储的系统（如网站用户信息、银行账户明细、电商订单记录等）。它主要用于执行以下四种基本操作，在业界常被称为 CRUD：主要进行创建，读取，删除，更新操作。无论是 MySQL、PostgreSQL、SQL Server 还是 Oracle，它们都遵循基本的 SQL 标准。也就是一种指挥数据库做什么操作的指令语句。

- MySQL：MySQL 是一种**关系型数据库管理系统 (RDBMS)**，它是目前全球范围内使用最广泛的开源数据库系统。**SQL (Structured Query Language)** 是与 MySQL 交互的语言，全称为“结构化查询语言”。通过编写简单的 SQL 语句，你可以对数据进行“增删改查”（CRUD）。

# XAMPP
**XAMPP** 是一个非常经典且功能强大的**免费集成开发环境包**，它的名字其实就是它所包含软件的缩写，直观地展示了它能为你提供什么：
- **X**：代表**跨平台 (Cross-platform)**，意味着它可以在 Windows、Linux 和 macOS 上运行。
    
- **A**：代表 **Apache**，这是目前全球使用量最大的 Web 服务器软件（负责接收你的网页请求并返回内容）。
    
- **M**：代表 **MariaDB**，这是 MySQL 的一个开源分支，也是目前绝大多数 PHP 项目的首选数据库。
    
- **P**：代表 **PHP**，也就是我们之前提到的脚本语言。
    
- **P**：代表 **Perl**，一种较老但功能强大的脚本语言（现在用得较少，但在 XAMPP 里依然内置）。

# Apache
Apache（全称：**Apache HTTP Server**）是世界上最著名的开源 Web 服务器软件之一。你可以把它理解为**互联网上的一位“大管家”**，专门负责处理用户从浏览器发出的网页请求。
