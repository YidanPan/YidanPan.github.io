# 题目
给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

输入
```c
bool isValid(char* s) {

}
```

## 正确解答：
```valid answer
bool isValid(char* s) {

    int len=strlen(s);

    char stack[len+1];

    int cont=0;

    int i;

    for(i=0;i<len;i++){

        char c=s[i];

        if(c=='('||c=='{'||c=='['){

            stack[cont++]=c;

        }else{

            if(c==')'){

                if(cont==0||stack[cont-1]!='('){

                    return false;

                }else{

                    cont--;

                }

            }else if(c=='}'){

                if(cont==0||stack[cont-1]!='{'){

                    return false;

                }else{

                    cont--;

                }

            }else if(c==']'){

                if(cont==0||stack[cont-1]!='['){

                    return false;

                }else{

                    cont--;

                }

            }

        }

    }

    if(cont!=0){

        return false;

    }else{

        return true;

    }

}
```
