# MAC地址 IP地址
- mac地址是物理绝对地址，是收件地址，处于数据链路层中，是全球唯一的地址。表示网卡在网络中的绝对位置
- ip地址是网络局给的地址，是收件人，是在网络层中，网卡上需要配置好ip地址才能工作
	- ipv4：198.168.1.1  由四位0-255的数字构成，小数点隔开
	- ipv6：新造的
- 我们自己填写ip地址和内容，操作系统会 自动补充mac地址从网卡发出
- DHCP协议：能够动态分配IP地址。当设备连上网线，会自动向路由器发送DHCP协议请求分配IP地址。路由器通过dhcp回复报文发送回去。在一个局域网中一个ip地址也是唯一的。
- ARP协议：计算机a向计算机b发送信息，需要先通过arp协议发送给所有设备，只有计算机b能返回它的mac地址，a就会收到并缓存它的mac地址，然后通过网卡发送出去。
# 路由器 交换机
- 交换机：把数据包发送到正确位置。交换机根据数据包中的mac地址找到对应的物理端口。一台交换机有很多个端口，他们都有自己的编号。
- 计算机网卡通过网线连接到交换的网口上，就能确定一个物理端口。交换机每次通过查询mac地址表来查询对应端口，再从这个端口发送出去。
- 每个数据包有两个mac地址。一个是发送方的mac地址，为源地址。还有一个接收方的mac地址，为目标mac
- 路由器有两种接口：LAN口（多个）连接家庭网络设备。WAN口只有一个，用来接入运营商网络来接入因特网
- 子网划分：IP和子网掩码取与，结果相同的是在同一子网之下，反之则不同。用1的数量表示掩码，如255.255.255.0=24 用IP/掩码来表示子网
- TCP/IP协议规定不同子网不能够交流，得通过网关来转发。网关上有两个网卡，配置了两个IP地址。一台计算机发送数据包的时候先判断对方是否和自己在同一子网下，若是，则直接从网卡发出。反之，则把mac地址改为网关的mac地址发出，网关拿到数据后查询接收方是属于子网2，网关修改mac地址发出
- 路由：根据目标IP决定如何发送数据包。这是一种行为。
- SNAT（源地址转换技术）：路由器发送的时候改变IP地址
- TCP传输层协议：源端口和目标端口。SNAT就需要修改源端口和目标端口。UDP协议同理
- ICMP协议（常用来ping命令检测网络联通性）：IP地址+type code，无端口信息
- DNAT（目标地址转换）：作用是向内网转发请求
# TCP协议 UDP协议
 - 两者均工作在传输层，负责程序间的数据传输
 - TCP协议是基于连接，类比打电话，可以收到实时的反馈
	- 三次握手：确认连接的过程。客户端向服务端发送连接请求（SYN包）->若对方同意则返回一包SYN+ACK包 -> 我方确认后返回SYN包。
		本质上解决网络信道不可靠问题，在不可靠的信道上建立可靠的连接
		如果是两次握手，当客户端向服务端发送一次数据包，结果数据包1在网络中阻塞了，于是第二次发送了数据包2，接收成功返回SYN+ACK建立一次连接，这时数据包1成功到达服务端，服务器误以为是客户端再次发送连接请求，于是处于等待数据的阶段，这样两者的状态不一致。
	- 传输确认
	- 四次挥手：处于连接状态的客户端和服务端都可以发送关闭连接的请求。需要通过四次挥手来关闭连接。
		客户端向服务端发起关闭连接请求，发送FIN包，服务端接收后发送ACK包，此时客户端处于等待关闭状态，还可以继续发送没有发送完全的数据包，之后客户端再次发送FIN包，服务端接收后发送ACK包并立即关闭连接，客户端等待超过超时时间后才会关闭连接。
 - UDP协议是基于非连接，类比写信，很多都是未知的

# DNS协议
- 访问一个网站最重要的就是访问这个网站的域名。但其实通过IP地址或者域名都是可以访问网站的。
- 域名是和IP地址一一对应的，是为了方便使用记忆。
- DNS协议：用户输入域名，需要查询相应的IP地址，这个查询的协议就是DNS协议。
	查询的时候主机会向上一级的DNS服务器发送DNS报文请求，DNS服务器收到这一帧查询报文后会在自己缓存的DNS池中查找这个域名的记录找到对应IP地址。若找不到会向更上一级的DNS服务器发送DNS请求，以此类推。最终返回对应的IP地址。
	
	浏览器知道对应IP地址后会构建HTTP协议数据包，通过HTTP协议最终获取需要的网页。浏览器为了方便快速查询，也会缓存一些域名对应的IP地址进行快速查询。

# SSH协议
- ssh是安全外壳协议，Secure Shell，是一种加密网络协议。最著名的例子就是用户通过该协议进行远程登录到计算机系统。
- SSH 使用非对称加密技术来保护客户端与服务器之间的连接安全。在非对称加密中，需要使用两种密钥：公钥和私钥。公钥用于加密数据，而私钥则用于解密数据。当您连接到 SSH 服务器时，服务器会将其公共密钥发送给客户端。客户端使用这个公共密钥来加密一个随机生成的会话密钥，然后将其返回给服务器。服务器则使用其私有密钥来解密会话密钥，从而建立安全连接。
