1.基础语法

字符串

  • 反斜杠可以用来转义，使用 r 可以让反斜杠不发生转义。 如 r”this is a line with \n” 则 \n 会显示，并不是换行
  • 按字面意义级联字符串，如 “this “ “is “ “string” 会被自动转换为 this is string。
  • 字符串可以用 + 运算符连接在一起，用 * 运算符重复。
  • 单引号和双引号没区别
  • Python 中的字符串有两种索引方式，从左往右以 0 开始，从右往左以 -1 开始。
  • Python 没有单独的字符类型，一个字符就是长度为 1 的字符串。
  • 字符串切片：str[start:end:step] 其中 start（包含）是切片开始的索引，end（不包含）是切片结束的索引。

Print输出

  • print输出默认是换行，不换行需要在变量末尾加上 end=””
  • Python 3 中整数字面量不允许前导零（如 080），八进制数必须使用 0o 前缀（如 0o17），十六进制使用 0x 前缀（如 0x69），二进制使用 0b 前缀。

第一章

  • python中的name意味着变量，可以随时和值绑定，在赋值语句中，会先执行等号右侧的值，然后依次从左到右赋值给左侧的变量
  • 赋值的时候内置函数也可以被赋值，变量也可以被赋值为函数，f=max，之后还可以继续f=1，重新赋值为常量
  • 一个语句可以同时给多个变量赋值，从左到右的顺序依次赋值
  • 代码语句只是被执行做出改变
  • print是个函数，它的返回值是none，但是它会有副作用会打印出东西
    ![[Pasted image 20260716225622.png]]
  • 所谓函数就是把名称绑定在一组运算上。def中写的参数是形式参数，只是提供一个名称为后续提供一个赋值的容器。
  • The name of a function is repeated twice, once in the frame and again as part of the function itself. The name appearing in the function is called the intrinsic name. The name in a frame is a bound name.
  • function signature指的是函数形式参数的描述。形式参数的个数是固定的，传入的时候不能随意更改。但是内置函数的参数个数是没有被定义的，所以传入参数个数是不定的
  • 定义函数的时候并不等于被执行，单独一步是进行整个函数的定义，但是没有被代入具体的值进行运算
  • 注意区分函数返回值并不是绑定在函数名称上的
  • 框架分为全局框架和局部框架，整个函数名称是全局框架，只有调用函数传入真实参数的时候才是创建局部框架
  • 每个函数被调用的时候都是会新创建一个环境
  • 函数的形式参数的名称仅仅作用于函数内部，每个函数的参数都是独立的
  • 函数使用看清定义域、值域、主体范围
  • 函数定义通常包括描述该功能的文档，称为 _docstring_，必须与函数主体一起缩进。文件字符串通常用三引号。第一行用一行描述了该函数的工作。
  • 在函数定义中，可以给其中一个参数赋值为常数，如果实际调用没有给出具体值，就按照定义时的常数去计算，提供的话就忽略定义给的常数、
  • 一些永不变化的值，如基本常数 k ，可以被束缚在函数体或全局参考系中。
  • 每条语句都描述了解释器（interpreter）状态的一种变化，执行语句就是把这种变化真正应用到解释器中。
  • statement是语句，是被执行使解释器状态发生改变的语句。expression是表达式，是计算出最终值的。解释器状态就是当前python中记住的东西
  • return 后面的表达式不会在定义函数时立即求值，而是会被保存起来，等到以后真正调用这个函数时才进行计算。
  • 函数定义时写def的时候只是建立函数对象，没有执行，return语句也没有被执行，只是被保存起来，等到调用的时候再执行
  • 函数体内部的赋值语句不会影响全局帧
  • 一个表达式如果被 Python 用来判断真假，而不是获取它的实际值，那么它就在布尔上下文中。
  • 三个基本的逻辑运算符：and/or/not 可以用作bool 运算。一个逻辑表达式的真假值，有时可以在不计算所有子表达式的情况下确定。
  • 布尔表达式的实际执行顺序是从左到右，比如说是and操作，如果左侧的表达式结果为false，那么就不会执行右侧表达式直接判断为false，反之结果就是右侧表达式的结果。注意这种逻辑表达式返回值不一定是布尔值，为左侧或者右侧表达式的真实值。
  • 右侧 = 后面的所有表达式，会先全部计算完成，然后才进行左侧变量的重新绑定。
  • 循环语句的最后循环条件的变量值一定得改变不然会变成无限循环。在每一次执行中改变某些变量，使条件最终可能变成 False。
  • 环境就是一个或者多个frame,每次调用一个函数就是创建一个新的frame，frame决定了查询的顺序，global是最后查询的，这个解释了为什么当变量名一样时函数内部的优先级会高于全局变量。
  • 通过高阶函数，我们开始看到一种更强大的抽象：某些函数能够表达通用的计算方法，而独立于它们所调用的具体函数。 但是缺点是全局环境帧（global frame）会变得拥挤不堪，塞满了各种小函数的名称，而且这些名称还必须互不相同。
  • 一般函数return结束后就会被内存回收消失，但是如果返回值是一个函数又被重新赋值给新的变量，那么这个局部函数就不会消失。
